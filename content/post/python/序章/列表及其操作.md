# 列表及其操作

​    **列表(list)** 是python常见的一种数据结构类型，可以理解为C语言中的数组。因此列表的基础操作也与数组非常类似：
~~~python
ls = ['hello','world','redline','trek']
print(ls)	 #按格式输出整个列表
print(ls[0]) #输出列表第一个元素
print(ls[-1])#输出列表倒数第一个元素
print(f'My first bicycle was a {ls[3].title()}')#使用列表中的值

ls[0] = 'Hello' #修改列表中的第一个元素
~~~

除了类似于c语言的一些常规用法,列表还包含了一些额外的用法，如上面的代码片段所示。

## 添加、删除

### 列表尾添加元素

​    可以使用`append()`方法进行追加，例如：

~~~python
motocycles = ['honda', 'yamaha', 'suzuki']
print(motocycles)

motocycles.append('ducati')
print(motocycles)
~~~

运行结果如下：

~~~bash
['honda', 'yamaha', 'suzuki']
['honda', 'yamaha', 'suzuki', 'ducati']
~~~

### 列表中插入元素

​    可以使用`insert()`方法进行插入，例如：
~~~python
motocycles = ['honda', 'yamaha', 'suzuki']

motocycles.insert(0,'ducati') #在索引0处添加空间并插入
print(motocycles)
~~~

运行结果如下：

~~~bash
['ducati', 'honda', 'yamaha', 'suzuki']
~~~

### 列表中删除元素

​    可以使用`del`语句和`pop()`方法,两者的用法不同，前者更倾向于 **指定列表中某一个元素进行删除** ，后者则是 **类似与栈一样弹出列表末尾的元素**。例如：
~~~python
m1 = ['honda','yamaha','suzuki']
m2 = ['honda','yamaha','suzuki']

del m1[-1]
poped = m2.pop()

print(m1,m2)
print(poped)
~~~

运行结果如下：
~~~bash
['honda', 'yamaha'] ['honda', 'yamaha']
suzuki
~~~

当然，`pop()`方法也可以指定某一个具体位置的元素进行删除，只需要在方法参数中传递具体的索引即可，这里就不再赘述。

​    假设需要根据值匹配对某个 **不知道索引的元素** 执行删除操作，则可以使用`remove()`方法：
~~~python
m = ['honda', 'yamaha', 'suzuki', 'ducati']
m.remove('ducati')
print(m)
~~~

运行结果如下：

~~~python
['honda', 'yamaha', 'suzuki']
~~~

> [!NOTE]
>
> `remove()`方法只会删除第一个匹配的元素，如果需要删除列表中所有匹配的元素，则需要使用循环。

## 管理列表

### 排序

​    使用`sort()`方法可以对列表中的元素进行 **永久** 排序：
~~~python
cars = ['bmw','audi','toyota','subaru']
cars.sort()
print(cars)
~~~

运行结果如下：
~~~bash
['audi', 'bmw', 'subaru', 'toyota']
~~~

可以看到在不传递参数的情况下，默认会按照 **首字母的字母表顺序** 进行排序，对数则是 **从小到大** 。

> [!TIP]
>
> 假设列表中同时存在大小写元素，则 **首字母大写的元素会排在首字母小写的前面** 。

`sort()`方法接受参数`reverse=True`，能够按照 **反向的字母表顺序 ** 对列表进行排序，对数则是 **从大到小** 。

> [!NOTE]
>
> `sort()`方法的排序是永久性的，一旦排序完成，原来列表的顺序就会丢失。如果想要保留原来的顺序，需要使用`sorted()`函数（注意函数和方法不是同一个东西）：
>
> ~~~python
> cars = ['bmw','audi','toyota','subaru']
> print(sorted(cars))
> print(cars)
> ~~~
>
> 运行结果如下：
> ~~~bash
> ['audi', 'bmw', 'subaru', 'toyota']
> ['bmw', 'audi', 'toyota', 'subaru']
> ~~~
>
> 可以看到原来列表的顺序并没有被改变。同样的，`sorted()`方法也接受`reverse=True`参数：
> ~~~python
> cars = ['bmw','audi','toyota','subaru']
> print(sorted(cars,reverse=True))
> print(cars)
> ~~~
>
> 运行结果如下：
>
> ~~~bash
> ['toyota', 'subaru', 'bmw', 'audi']
> ['bmw', 'audi', 'toyota', 'subaru']
> ~~~

### 反转列表

​    可以使用`reverse()`方法来反转列表，会改变原有列表中的顺序：
~~~python
cars = ['bmw','audi','toyota','subaru']
cars.reverse()
print(cars)
~~~

运行结果如下：
~~~bash
['subaru', 'toyota', 'audi', 'bmw']
~~~

### 求表长

​    使用`len()`函数可以确定列表的长度：
~~~python
nums = [1,2,3,4,5,6]
print(len(nums))
~~~

运行结果如下：
~~~bash
6
~~~

### 求最值

​    可以用函数`min()`、`max()`、`sum()`来求数值列表中的**最小、最大、求和**的值,例如：
~~~python
nums = [1,2,3,4,5,6,7]
print(min(nums),max(nums),sum(nums))
~~~

运行结果如下：

~~~bash
1 7 28
~~~

## 推导式

​    假设需要生成列表的话，一个方法单纯使用for循环，后面会介绍到。另一种方法就是利用 **列表推导式（list comprehension）** ，其本质是将for循环和创建新元素的代码合并为了一行，并自动追加新元素：

~~~python
squares = [value**2 for value in range(1,11)]
print(squares) # 平方数列表
~~~

运行结果如下：
~~~python
[1, 4, 9, 16, 25, 36, 49, 64, 81, 100]
~~~

正则表达式的描述如下：
~~~
<变量名> = [<表达式> for <参与变量> in <数值范围>]
~~~

可能描述不大准确，但只要理解怎么用的就可以了。

## 切片

   在处理列表的时候可以只选择列表的一部分进行处理，被处理的列表部分被称为 **切片（slice）** 。可以如下面所示的例子来处理切片：

~~~ python
player = ['charles','martina','michael','florence','eli']
print(player[0:3])
~~~

运行结果如下：
~~~bash
['charles', 'martina', 'michael']
~~~

可以看到输出了前三个元素。因此可以简单的总结：

~~~
<列表名>[ (<起始索引>) : (<目标索引+1>) ]
~~~

至于为什么目标索引要+1，这是由于python的底层机制导致的，python在进行判断逻辑的时候不会输出终止条件对应的值，不理解问题也不大。

给 **起始索引** 和 **目标索引** 的原因是这两个是可以不要的，假设不给起始索引，则默认从列表头开始；不给目标索引，默认执行到列表尾；两个都不给就和直接输出列表没有区别，例如：
~~~python
player = ['charles','martina','michael','florence','eli']
print(player[:3]) #从表头开始输出到索引2的元素
print(player[:-2]) #从表头开始输出到倒数第2个元素
print(player[2:]) #从索引2开始输出到表尾
print(player[-2:]) #从倒数第2个元素输出到表尾
print(player[:])  #输出列表
~~~

运行结果如下：
~~~bash
['charles', 'martina', 'michael']
['charles', 'martina', 'michael']
['michael', 'florence', 'eli']
['florence', 'eli']
['charles', 'martina', 'michael', 'florence', 'eli']
~~~

## 列表复制

​    有时候我们需要复制列表，这个时候就可以利用上述提到的 **切片** ，如下所示：
~~~python
foods = ['pizza','falafel','carrot cake']
Myf = foods[:]
print(foods,Myf)
~~~

运行结果这里就不列出了，为了验证这是两个独立的列表，我们进行一些操作：
~~~python
foods = ['pizza','falafel','carrot cake']
Myf = foods[:]
del Myf[0]
print(foods,Myf)
~~~

运行结果如下：
~~~bash
['pizza', 'falafel', 'carrot cake'] ['falafel', 'carrot cake']
~~~

> [!WARNING]
>
> 下面的复制操作是错误的：
> ~~~python
> foods = ['pizza','falafel','carrot cake']
> Myf = foods
> del Myf[0]
> print(foods,Myf)
> ~~~
>
> 运行结果如下：
> ~~~bash
> ['falafel', 'carrot cake'] ['falafel', 'carrot cake']
> ~~~
>
> 可以看到两个列表的索引0元素都被删除了，说明两个变量都是指向的同一个列表，同时这也说明了切片的本质是创建了一个新的列表。

## 元组 

​    有时候需要类似于列表那样连续的数据，但又不希望能够变动其中的元素，就可以使用 **元组（tuple）**。

​    元组看起来很像列表，但定义元组的时候使用的是圆括号`()`，访问其中的数据和列表操作一致：

~~~python
nums = (199,211)
print(nums[0])
~~~

运行结果如下：

~~~bash
199
~~~

假设我们修改其中的元素，则会收到来自python解释器的报错：

~~~python
nums = (199,211)
nums[0] = 200
~~~

~~~bash
Traceback (most recent call last):
  File "d:\Coding\Python-Study\study.py", line 2, in <module>
    nums[0] = 200
    ~~~~^^^
TypeError: 'tuple' object does not support item assignment
~~~

可以看到解释器向我们说明，元组不支持元素赋值。同理，更改元组的长度也是不允许的。

> [!WARNING]
>
> 假设需要定义长度为1的元组，需要在元素后加上逗号：
>
> ~~~python
> nums = (28,)
> ~~~
>
> 这是因为元组是由逗号标识的，圆括号只是让元组更整洁更清晰。

元组的遍历和列表无异，这里不再赘述。对于元组，虽然其元素无法随意改动，但是可以更改变量，例如：
~~~python
nums = (28,123)
nums = (123,222)
print(nums)
~~~

运行结果如下：
~~~bash
(123, 222)
~~~

综上，假设需要在程序的整个生命周期内都不变的值，就可以使用元组。

---

​    综上所述，可以看到列表的操作本质上和数组没什么区别，只是python提供了更为方便的接口，处理的时候更便捷。

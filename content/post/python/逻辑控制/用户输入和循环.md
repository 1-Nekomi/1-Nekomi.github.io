# 用户输入和循环

​    大多数程序都需要数据，而很多程序的数据依赖于用户实时输入，因此需要能够正确处理用户的输入，可以使用`input()`函数来获取用户的输入：
~~~python
message = input("tell me something, and I will repeat it back to you.")
print(message)
~~~

运行结果如下：
~~~bash
tell me something, and I will repeat it back to you.
$ Hello World
Hello World
~~~

`input()`函数接受一个参数，用于向用户提示（prompt）请求输入的信息，而`input()`函数会默认将用户的输入解读为字符串，假设需要读取数值输入，则需要使用`int()`函数来进行转换：

~~~python
age = input('How old are you?\n')
age = int(age)
print(age+2)
~~~

运行结果如下：

~~~bash
How old are you?
$ 21
23
~~~

## for循环

​    每种高级语言都有自己的逻辑控制关键字，这里主要介绍python中用于控制循环的关键字之一：for

其用法用遍历列表简单说明：
~~~python
magicians = ['alice','david','carolina']
for magician in magicians:
    print(magician)
~~~

运行结果如下：
~~~bash
alice
david
carolina
~~~

上述python代码片段的第2行简单来说，就是从列表`magicians`的第一个元素开始，每次取当前索引的元素赋给变量`magician`，在for循环内就可以对变量`magician`进行处理。关键字`in`后面可以跟一个列表、列表切片、数值范围等等，不同场景可以用不同的数据结构。

同时需要注意 **for语句后的冒号** 和 **缩进**。

## `range()`函数

​    假设需要让该for循环的代码片段执行指定次数次，则可以是使用`range()`函数来生成一系列数：
~~~python
nums = ['h','e','l','l','o']
for i in range(0,5):
    print(nums[i])
~~~

运行结果如下：
~~~bash
h
e
l
l
o
~~~

> [!NOTE]
>
> 需要注意的是假设将上述代码片段中的`range(0,5)`改为`range(1,5)`则只会执行四次，这是因为 **`range()`函数让python从指定的第一个数开始数，并在到达第二个值时停止** 。
>
> 如果上述描述很难理解，那只需要知道对于`for i in range(x,y)`，则for循环会从x开始执行$y-x$次即可。

可以使用`range()`函数来创建一个对应的数值列表，需要使用`list()`函数来转换列表：
~~~python
nums = list(range(1,5))
print(nums)
~~~

结合上述的Note，这里可以猜一下运行结果是什么样子的。

{{< spoiler >}}运行结果如下：

~~~bash
[1, 2, 3, 4]
~~~

{{< /spoiler >}}

`range()`函数还接受 **步长** 参数，用于指定 **每次增长的幅度** ，例如：

~~~python
nums = list(range(2,11,2))
print(nums)
~~~

运行结果如下：
~~~bash
[2, 4, 6, 8, 10]
~~~

## while循环

​    while循环是另一种循环形式，其会一直运行到不满足while语句中的条件为止。例如：
~~~python
number = 1
while number <= 5:
    print(number)
    number+=1
~~~

运行结果如下：

~~~bash
1
2
3
4
5
~~~

当然，配合 **用户输入** ，可以让用户自由选择退出循环的时机，例如：
~~~python
number = ''
while number != 'exit':
    number = input()
    if number != 'exit':
        print(number)
~~~

运行结果如下：
~~~bash
$hello
hello
$world
world
$exit
~~~

当输入`'exit'`字符串时，就会退出循环结束程序。

当然，在使用while循环时可以使用布尔变量来决定是否继续循环，这是和for循环最大的区别，for循环很难依赖单纯的布尔变量来决定是否循环。

~~~python
active = True
while active:
    message = input()
    
    if message == 'quit':
        active = False
    else:
        print(message)
~~~

运行结果如下：
~~~bash
$hello world
hello world
$quit
~~~

同理，python中的while循环也可以使用`break`和`continue`关键字，作用与C语言中的一致，这里就不再赘述。

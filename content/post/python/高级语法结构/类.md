# 类

​    目前的编程主要分为 **面向过程编程** 和 **面向对象编程**，C语言就是典型的面向过程编程的语言，而python既可以面向过程也可以面向对象，而 **类（class）** 则是面向对象编程专属的概念，基于类可以创建 **对象（object）** ，并能够使用该对象具备的通用行为。下面介绍类在python中是如何定义并使用的。

## 创建和使用类

 下面是一个创建类的简单例子：
~~~python
class Dog:
    
    def __init__(self, name, age):
        self.name = name
        self.age = age
        
    def sit(self):
        print(f"{self.name} is now sitting.")

    def roll_over(self):
        print(f"{self.name} rolled over! ")
~~~

### init方法

​    在上述类中存在一个特殊的方法`__init__()`，该方法主要是 **用来初始化对象属性** 的，当将对象实例化时会自动调用`__init__()`方法。而在参数列表中存在一个`self`参数，该参数主要是 **指向调用该方法的对象本身** ，因此对于一个类中的方法，该参数必不可少，而在调用方法时，不需要显式传递该参数，python会自动将调用该方法的对象作为参数传递给方法。

### 实例化

​    利用类创建对象的过程称为 **实例化** 。例如：
~~~python
my_dog = Dog("Nini", 6)
my_dog.sit()
my_dog.roll_over()
~~~

运行结果如下：
~~~bash
Nini is now sitting.
Nini rolled over! 
~~~

在实例化就可以使用类中的方法。

### 管理属性值

​    在`__init__()`方法中可以给属性设置默认值，例如：
~~~python
class Car:
    
    def __init__(self, make, model, year):
        self.make = make
        self.model = model
        self.year = year
        self.odometer_reading = 0

    def get_info(self):
        info = f"{self.year} {self.name} {self.model}"
        return info
    
    def read_odometer(self):
        print(f"This car has {self.odometer_reading} miles on it.")

my_car = Car('audi', 'a4', 2024)
print(my_car.get_info())
my_car.read_odometer()
~~~

运行结果如下：

~~~bash
2024 audi a4
This car has 0 miles on it.
~~~

这样就可以给汽车类设置一个默认为0的里程数。

> [!TIP]
>
> 当然，设置默认值还可以这样设置：
> ~~~python
> class Car:
>     
>     odometer_reading = 0
>     
>     def __init__(self, make, model, year):
>         self.make = make
>         self.model = model
>         self.year = year
>     
>     def get_info(self):
>         info = f"{self.year} {self.make} {self.model}"
>         return info
>     
>     def read_odometer(self):
>         print(f"This car has {self.odometer_reading} miles on it.")
> ~~~

​    如果需要 **修改属性值** ，则分为两种办法：

- 直接修改，例如：
  ~~~python
  class Car:
      ...
  
  my_car = Car('audi', 'a4', 2024)
  my_car.odometer_reading = 23
  my_car.read_odometer()
  ~~~

  运行结果如下：
  ~~~bash
  This car has 23 miles on it.
  ~~~

  这种方法会增加一定的安全风险，比如可能会让一些恶意程序修改数据，同时也不利于增加模块的内聚性。

- 利用方法修改，例如：
  ~~~python
  class Car:
      ...
      
      def update_odometer(self, mileage):
          self.odometer_reading = mileage
  
  my_car = Car('audi', 'a4', 2024)
  my_car.update_odometer(23)
  my_car.read_odometer()
  ~~~

  运行结果同上。这种方法能一定程度上避免数据被误修改，同时还能加上更多的检测逻辑，加强模块的内聚性和保证数据安全。例如在上述代码上加上检测逻辑：不允许里程计数据倒转，请自行实现。

## 访问控制

​    假设有Java或者C++编程基础，会发现python中没有类似于`public`、`private`、`protected`这类访问权限控制关键字，默认情况下，python中类方法和属性都是`public`公开的，在python中控制访问权限是通过在方法名前加上下划线实现的。

| 访问级别               | 命名约定                    | 描述                                                         |
| :--------------------- | :-------------------------- | :----------------------------------------------------------- |
| **公有 (Public)**      | 普通名称，例如 `name`       | 默认模式，可以从任何地方访问。                               |
| **受保护 (Protected)** | 单下划线开头，例如 `_name`  | 一种约定，表示“内部使用”。开发者应避免在类外部直接访问它，但 Python 本身并不会强制执行。 |
| **私有 (Private)**     | 双下划线开头，例如 `__name` | 触发**名称修饰（Name Mangling）** 机制。Python 会将其重命名为 `_ClassName__name`，这使得从外部意外访问变得更困难，但并非不可能。 |

> [!Note]
>
> 对于`protected`，python中并不存在这一类访问控制，上述提到的方法只是一种约定，在协作编码时需要注意。

## 继承

​    **继承（inheritance）** 是面向对象编程重要机制之一，如果要编写的类是另一个类的特殊版本，则可以使用继承。被继承的类被称为 **父类**， 新类被称为 **子类** 。子类会继承父类的所有属性和方法，同时还可以自定义自己的属性和方法。

### 子类的init方法

​    子类在进行初始化时可以通过父类的`__init__()`方法进行初始化，同时再在自己的`__init__()`方法中定义自己的属性。例如：
~~~python
class Car:
    odometer_reading = 0
    
    def __init__(self, make, model, year):
        self.make = make
        self.model = model
        self.year = year
    
    def get_info(self):
        info = f"{self.year} {self.make} {self.model}"
        return info
    
    def read_odometer(self):
        print(f"This car has {self.odometer_reading} miles on it.")

    def update_odometer(self, mileage):
        self.odometer_reading = mileage

class ElectricCar(Car):
    
    def __init__(self,make,model,year,power):
        super().__init__(make,model,year)
        self.power = power

my_leaf = ElectricCar('nissan', 'leaf', 2026, 100)
print(my_leaf.get_info())
~~~

运行结果如下：
~~~python
2026 nissan leaf
~~~

上述代码片段中的`super()`主要是代指 **父类**，假设子类需要调用父类的方法则需要使用`super()`函数（这里提一嘴，假设类自己调用自己的方法，则需要带上`self`）。

### 父类方法重写

在上述代码段中，我们输出子类信息还是用的从父类继承得到的方法，而父类的方法并不能输出子类新加入的`power`功耗这一新属性，那么可以将父类中的`get_info()`方法进行重写：
~~~python
class Car:
   ...

class ElectricCar(Car):
    
    def __init__(self,make,model,year,power):
        super().__init__(make,model,year)
        self.power = power
    
    def get_info(self):
        def get_info(self):
        info = f"{self.year} {self.make} {self.model} {self.power}"
        return info

my_leaf = ElectricCar('nissan', 'leaf', 2026, 100)
print(my_leaf.get_info())
~~~

运行结果如下：
~~~bash
2026 nissan leaf 100
~~~

可以看到`power`属性被输出了，而从父类继承的`get_info()`方法没有被调用。

## 组合

​    当一个类中的属性和方法越来越多时，维护成本会很明显上升，但此时我们可以通过将一部分属性和方法分离出去作为一个独立的类，再在原来的大类中将小类作为成员包含进去。以上面的类为例：
~~~python
class Car:
    ...

class Battery:
    
    def __init__(self, battery_size=40):
        self.battery_size = battery_size

    def get_battery(self):
        print(f"This car has a {self.battery_size}-kWh battery.")

class ElectricCar(Car):
    
    def __init__(self,make,model,year,power):
        super().__init__(make,model,year)
        self.power = power
        self.battery = Battery()
        
    def get_info(self):
        info = f"{self.year} {self.make} {self.model} {self.power}"
        return info
    
my_leaf = ElectricCar('Nini','leaf',2024,100)
print(my_leaf.get_info())
my_leaf.battery.get_battery()
~~~

运行结果如下：
~~~bash
2024 Nini leaf 100
This car has a 40-kWh battery.
~~~

因此在设计类的时候需要明确各个类的职能范围，合理划分类能显著降低类的复杂性，维护类也会更加方便。

## 导入类

为了让主程序更简洁，也需要像导入函数那样使用导入类，以`Car`类为例，编写一个`car.py`文件，其中包含了`Car`类所有代码，包含`Battery`和`ElectricCar`类，在主程序中编写代码：
~~~python
# main.py
from car import Car    

my_car = Car('Nini','a4',2025)
print(my_car.get_info())

my_car.update_odometer(199)
my_car.read_odometer()
~~~

运行结果如下：

~~~bash
2025 Nini a4
This car has 199 miles on it.
~~~

类导入逻辑和函数区别不大，很多地方都可以借鉴函数导入：

- 导入多个类：
  ~~~python
  from <module_name> import <class_name> [,<class_name>]
  ~~~

- 导入模块：

  ~~~python
  import <module_name>
  ~~~

- 导入模块中所有类：
  ~~~python
  from <module_name> import *
  ~~~

当需要导入大量类时，最好使用`module_name.class_name`这种语法去访问类，这样可以避免不明确该类来自哪个模块，也能提高代码可维护性。

同时，导入类和模块时也可以使用`as`来使用别名，也可以在模块中导入类和模块。

综合来看，python中的类机制相对比较简单，没有过多的概念，用法也相对比较简单，这使得在python中使用类很快速便捷。

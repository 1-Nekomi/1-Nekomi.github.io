# 字典

​    **字典（dictionary）** 在python中是一系列键值对，每个键都跟一个值关联，可以通过对应的键来访问对应的值，例如：
~~~python
alien = {'color': 'green', 'points': 5}
print(aline['color'],alien['points'])
~~~

运行结果如下：
~~~bash
green 5
~~~

## 添加键值对

​    字典是一种动态结构，可以随时在其中添加键值对，要添加键值对，需要依次指定字典名、用方括号`[]`括起来的键和与该键对应的值,例如：
~~~python
alien = {} # 空字典
print(alien)

alien['x_pos'] = 3
alien['y_pos'] = 11
print(alien)
~~~

运行结果如下：
~~~bash
{}
{'x_pos': 3, 'y_pos': 11}
~~~

## 修改字典中的值

​    同样的，假设指定字典名、用方括号`[]`括起来的键和与键对应的值，可以修改对应的键值对，例如：
~~~python
alien = {'color': 'green', 'points': 5}
print(alien)

alien['color'] = 'red'
print(alien)
~~~

运行结果如下：
~~~bash
{'color': 'green', 'points': 5}
{'color': 'red', 'points': 5}
~~~

## 删除键值对

​    假设需要删除某个键值对，可以使用`del`语句，必须指定字典名和键,例如：
~~~python
alien = {
    'color': 'green', 
    'points': 5, 
    'useless': '11123'
}
print(alien)

del alien['useless']
print(alien)
~~~

运行结果如下：
~~~bash
{'color': 'green', 'points': 5, 'useless': '11123'}
{'color': 'green', 'points': 5}
~~~

> [!NOTE]
>
> 被删除的键值对会永远消失。

## `get()`方法

​    假设在字典中访问一个不存在的键值对，那么会引发错误。而为了避免这个错误的产生，可以使用`get()`方法来返回一个默认值，其原型如下：
~~~python
<字典名>.get(<键>,<message>)
~~~

假设存在键，则会返回值；若没有，则会返回第二个参数`message`。

下面是个简单的例子：
~~~python
alien = {'color': 'green', 'points': 5}

Message = alien.get('x_pos','no x_pos')
print(Message)
~~~

运行结果如下：
~~~python
no x_pos
~~~

## 遍历字典

​    字典的遍历分为三种形式，依次是遍历 **键值对、键、值**，同时也可以按照特定顺序进行遍历。下面分别进行介绍。

### 遍历键值对

​    以下面的字典为例：
~~~python
user = {
    'name': 'xixizi',
    'love': 'football',
    'age': 18,
    'language': 'Chinese'
}
~~~

我们遍历键值对的话需要在循环中声明两个变量用于接收键和值，同时使用`items()`方法，该方法会返回一个键值对列表。例如：
~~~python
for key,value in user.items():
    print(f"key is {key}")
    print(f"value is {value}\n")
~~~

运行结果如下：
~~~bash
key is name
value is xixizi

key is love
value is football

key is age
value is 18

key is language
value is Chinese
~~~

### 遍历键

​    假设不想看键对应的值，只需要在循环中声明一个变量用于接收`keys()`方法返回的键，例如：

~~~python
# user字典

for key in user.keys():
    print(f"key is {key}")
~~~

运行结果如下：
~~~bash
key is name
key is love
key is age
key is language
~~~

就算不显式给出`keys()`方法，实际上结果也和上述一致，代码如下：
~~~python
# user字典

for key in user:
    print(f"key is {key}")
~~~

如果预先对键进行非破坏性排序（使用`sorted()`函数），那么就可以按特定顺序遍历字典中所有键，例如：
~~~python
# user字典

for key in sorted(user.keys()):
    print('key is '+key)
~~~

运行结果如下：
~~~bash
key is age
key is language
key is love
key is name
~~~

### 遍历值

​    同理，`value()`方法会返回字典中的值，因此遍历值和遍历键上本质没有区别：
~~~python
# user字典

for value in user.values():
    print(f"value is {value}")
~~~

运行结果如下：
~~~bash
value is xixizi
value is football
value is 18
value is Chinese
~~~

## 集合

​    在上述遍历的过程中，假设我们需要筛选重复的数据，则可以使用 **集合（set）** ，集合中的每一个元素都是独一无二的，这个特性使其非常适合用来筛选重复数据，下面是一个简单的例子：
~~~python
user_favor = {
    'jack': 'c',
    'sarah': 'cpp',
    'edward': 'java',
    'phill': 'python',
    'jen': 'python'
}

for language in set(user_favor.values()):
    print(language.title())
~~~

运行结果如下：
~~~bash
Cpp
Python
Java
C
~~~

假设需要直接定义集合，则可以按照下面的例子进行定义：
~~~python
languages = {'c','cpp','python'}
print(languages)
~~~

运行结果如下：
~~~bash
{'c', 'python', 'cpp'}
~~~

## 嵌套

​    类似于`if-else`嵌套，字典也可以嵌套，嵌套形式分为 **字典列表、字典中存放列表、字典中存放字典** 。

### 字典列表

​    假设我们定义三个字典，想要同时访问这三个字典中的键值对，分别使用它们的字典名去访问实在是太麻烦了，这个时候就可以用一个列表存放字典：
~~~python
alien0 = {'color': 'green','points': 5}
alien1 = {'color': 'red','points': 10}
alien2 = {'color': 'yellow','points': 15}

alien_list = [alien0,alien1,alien2]

pam1 = 'color'
pam2 = 'points'

for alien in alien_list:
    print(f"color:{alien[f"{pam1}"]} points:{alien[f"{pam2}"]}")
~~~

运行结果如下：
~~~bash
color:green points:5
color:red points:10
color:yellow points:15
~~~

### 字典中存放列表

​    字典中的键只能是基础数据类型，例如数字，字符串等，但值可以是其他数据结构，例如列表、字典等。因此我们可以在字典中存放列表：
~~~python
pizza = {
    'crust': 'thick',
    'toppings': ['mushrooms','extra cheese']
}

print(f"You ordered a {pizza['crust']}-crust pizza "
     "with the following toppings:")

for topping in pizza['toppings']:
    print(f"\t{topping}")
~~~

运行结果如下：
~~~bash
You ordered a thick-crust pizza with the following toppings:
        mushrooms
        extra cheese
~~~

> [!WARNING]
>
> 嵌套层级不应该过多，会严重影响代码的可读性。

### 字典中存放字典

​    在字典中存放字典也是可行的，但这样代码会明显变得很复杂，例如：
~~~python
users = {
    'aeinstein': {
        'age': 19,
        'location': 'shanghai'
    },
    
    'mcurie': {
        'age': 32,
        'location': 'guangdong'
    },
    
    'DDnsjh': {
        'age': 26,
        'location': 'hongkong'
    }
}

for user_name,user_info in users.items():
    print(f"Username: {user_name}")
    print(f"Age:{user_info['age']}\nLocation:{user_info['location']}\n")
~~~

运行结果如下：
~~~
Username: aeinstein
Age:19
Location:shanghai

Username: mcurie
Age:32
Location:guangdong

Username: DDnsjh
Age:26
Location:hongkong

~~~

---

可以看到字典是一种高级数据结构，很明显，字典使得信息的存储变得很简单，合理使用字典能减少代码对信息处理的复杂性。

# Python中的函数

​    **函数(function)** 相当于一个代码块，可以对其传递参数然后调用(call)，函数就会返回一个最终的结果。合理使用函数可以大幅提高代码的可读性和复用性。

## 定义

​    下面是python中一个简单的函数定义例子：
~~~python
def greet():
    """显示简单的问候语"""
    print("Hello!")

greet()
~~~

运行结果如下：

~~~bash
Hello!
~~~

其中文档字符串（docstring）`"""<text>"""`用于描述函数的作用。

同样的，python中也可以向函数传递参数，参数根据作用域分为形参和实参，这里就不再赘述。

## 参数传递

​    在python中，参数传递的方式分为 **位置参数** 和 **关键字参数**，前者类似于C语言中的参数传递,例如：
~~~python
def pet(animal_type, pet_name):
    print(f"I have a {animal_type}.")
    print(f"My {animal_type}'s name is {pet_name.title()}")
    
pet('hamster', 'harry')
~~~

运行结果如下：
~~~bash
I have a hamster.
My hamster's name is Harry
~~~

对于后者，需要在传递参数时显式给出形参名字,例如:
~~~python
def pet(animal_type, pet_name):
    print(f"I have a {animal_type}.")
    print(f"My {animal_type}'s name is {pet_name.title()}")
    
pet(animal_type='hamster', pet_name='harry')
~~~

运行结果同上。

> [!WARNING]
>
> 在调用函数时，位置参数不能出现在关键字参数之后。

​    在编写函数的时候，可以 **给每一个形参指定默认值** ，例如：
~~~python
def pet(pet_name, animal_type='dog'):
    print(f"I have a {animal_type}.")
    print(f"My {animal_type}'s name is {pet_name.title()}")
    
pet('harry')
~~~

运行结果如下：
~~~bash
I have a dog.
My dog's name is Harry
~~~

> [!WARNING]
>
> 当使用默认值时，需要在参数列表中先列出没有默认值的形参，再列出有默认值的形参，否则会发生错误，例如：
> ~~~python
> def pet(animal_type='dog', pet_name):
>     print(f"I have a {animal_type}.")
>     print(f"My {animal_type}'s name is {pet_name.title()}")
>     
> pet(pet_name='harry')
> ~~~
>
> 运行后会产生错误：
> ~~~bash
> line 1
>     def pet(animal_type='dog', pet_name):
>                                ^^^^^^^^
> SyntaxError: parameter without a default follows parameter with a default
> ~~~

假设需要让 **某一个字符串实参变为可选** ，则可以将其默认值指定为空字符串`''`，例如：
~~~python
def get_name(first_name, last_name, middle_name=''):
    """返回标准格式名字"""
    full_name = f"{first_name} {middle_name} {last_name}"
    return full_name

print(get_name('john','hooker'))
print(get_name('john','hooker','lee'))
~~~

运行结果如下：
~~~bash
john  hooker
john lee hooker
~~~

假设需要让 **某一个数值参数变为可选** ，可以使用`None`占位符，其等价于`False`，例如：
~~~python
def build_person(first_name, last_name, age=None):
    person = {'first': first_name, 'last': last_name}
    if age:
        person['age'] = age
    return person

print(build_person('jimi','horido'))
print(build_person('jimi','horido',21))
~~~

运行结果如下：
~~~bash
{'first': 'jimi', 'last': 'horido'}
{'first': 'jimi', 'last': 'horido', 'age': 21}
~~~

​    python中函数也可以返回，同样使用关键字`return`，但python函数可以返回很多数据类型。除了返回数、字符串以外，还可以返回字典、列表等。因为返回形式和C语言中的类似，这里就不再赘述。

​    假设需要传递 **任意数量的参数** ，则可以在某一个参数前加上`*`符号，一个`*`则会将该形参声明为元组，两个`*`则会将该形参声明为字典。元组一般是用于接收 **位置参数** ，例如：
~~~python
def make_pizza(*topping):
    """打印顾客点的所有配料"""
    print(topping)

make_pizza('mushrooms')
make_pizza('mushrooms', 'green peppers', 'extra cheese')
~~~

运行结果如下：
~~~bash
('mushrooms',)
('mushrooms', 'green peppers', 'extra cheese')
~~~

> [!WARNING]
>
> 元组中的元素是不可修改的。其次对于用于接收任意数量参数的形参必须放在参数列表中的最后面，例如：
> ~~~python
> def make_pizza(size,*toppings):
>     print(f"\nMaking a {size}-inch pizza with the following toppings:")
>     for topping in toppings:
>         print(f"- {topping}")
> 
> make_pizza(16,'pepperoni')
> make_pizza(12,'mushrooms','green peppers','extra cheese')
> ~~~
>
> 运行结果如下：
> ~~~bash
> Making a 12-inch pizza with the following toppings:
> - mushrooms
> - green peppers
> - extra cheese
> ~~~
>
> 假设将`size`和`toppings`形参列表中的位置互换，则会发生以下错误：
> ~~~bash
> Traceback (most recent call last):
>   line 6, in <module>
>     make_pizza(16,'pepperoni')
> TypeError: make_pizza() missing 1 required keyword-only argument: 'size'
> ~~~
>
> 可以看到解释器没能接收到`size`参数，所以必须将用于接收任意数量的形参放在参数表的最后面。

假设需要接收任意数量的 **关键字实参** ，则需要使用字典形参：
~~~python
def build_user(first,last,**user_info):
    user_info['first_name'] = first
    user_info['last_name'] = last
    return user_info

user = build_user('albert', 'einstein', location='shanghai', field='computer technology')
print(user)
~~~

运行结果如下：

~~~bash
{'location': 'shanghai', 'field': 'computer technology', 'first_name': 'albert', 'last_name':'einstein'}
~~~

## 实参修改

​    如果有C语言基础，就会知道在C语言中函数修改形参是无法影响到实参的，除非传递指针。在python中也是同理，但是假设传递的参数是类似于 **字典、列表、集合以及自定义类** 这种“可变”数据结构，那么在函数中的修改会影响到实参，例如：
~~~python
def change_list(lst):
    lst.append(4)  # 修改对象内部，外部可见
    lst[0] = 100   # 修改元素，外部可见

nums = [1, 2, 3]
change_list(nums)
print(nums)
~~~

运行结果如下：
~~~bash
[100, 2, 3, 4]
~~~

可以看到在函数中对形参的修改在实参上也生效了。

假设实在需要在函数中改变不可变对象，那么存在三种方式：

- 使用`return`语句

- 使用`global`描述符，将变量声明为全局，例如：
  ~~~python
  def change_global():
      global x
      x = 200
  
  x = 5
  change_global()
  print(x)
  ~~~

  运行结果如下：
  ~~~bash
  200
  ~~~

  但这样会破坏函数的封装性，加强程序的耦合性。

- 利用可变对象对其进行包装，例如：

  ~~~python
  def change_wrapper(wrapper):
      wrapper[0] = 999
  
  p = [5]  
  change_wrapper(p)
  print(p[0]) 
  ~~~

  运行结果如下：
  ~~~bash
  999
  ~~~

由于字典、列表这类数据结构属于可变对象，在函数中对其操作会改变实参中的数据，假设我们不想改动原来的数据，可以使用 **切片** 。还记得切片的本质吗？创造了一个切片等同于{{< spoiler >}}创建了一个对应列表部分的副本{{< /spoiler >}}。例如：
~~~python
def change_wrapper(wrapper):
    wrapper[0] = 999

p = [5]  
change_wrapper(p[:])
print(p[0]) 
~~~

运行结果如下：
~~~bash
5
~~~

可以看到原来的列表数据没有被改变。

## 函数模块

​    为了让主程序更加简洁，可以将函数分离，单独存储在一个 **模块（module）** 的独立文件中，再通过 **导入（import）** 操作导入到主程序中调用，例如创建一个`pizza.py`文件：
~~~python
# pizza.py
def make_pizza(size,*toppings):
    print(f"\nMaking a {size}-inch pizza with the following toppings:")
    for topping in toppings:
        print(f"- {topping}")
~~~

接着在同目录下创建`main.py`文件：
~~~python
# main.py
import pizza

pizza.make_pizza(16,'pepperoni')
pizza.make_pizza(12,'mushrooms','green peppers','extra cheese')
~~~

运行结果如下：
~~~bash

Making a 16-inch pizza with the following toppings:
- pepperoni

Making a 12-inch pizza with the following toppings:
- mushrooms
- green peppers
- extra cheese
~~~

当然，也可以 **只导入特定的的函数** ，相关语法如下：
~~~python
from <module_name> import <function_name> [,<other_function_name>]
~~~

如果觉得导入的模块或者函数名太长了，可以使用`as`关键字来 **给导入的模块或者函数指定别名** ：

~~~python
import <module_name> as <other_name>
from <module_name> import <function_name> as <other_name> 
~~~

假设需要 **一次性导入模块内所有函数** ，则可以使用`*`运算符：
~~~python
from <module_name> import *
~~~

---

可以看出python中的函数相比C中的函数，其功能本质上没有区别，但在参数传递和形参表声明上更加灵活。

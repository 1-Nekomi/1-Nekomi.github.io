# 文件和异常 - python

​    文件可以用于程序实时处理大量数据，而异常可以用于管理程序运行时出现的错误。

## 读取文件

### 写入文本

​    要读取一个文件，首先需要提供文件 **路径（path）**，选择路径需要导入`pathlib`模块中的`Path`类，传递文件 **相对路径或绝对路径** 创建一个基于`Path`类的对象，然后使用方法`read_text()`方法，就可以 **将文件中所有内容读出** ，例如：

~~~ python
from pathlib import Path

path = Path('data.txt')
contents = path.read_text()
print(contents)
~~~

~~~text
# data.txt
3.1415926535
  8979323846
  2643383279
~~~

运行结果如下：
~~~bash
3.1415926535
  8979323846
  2643383279
~~~

   假设仅仅需要 **读取文件的某一行** ，则可以使用`splitlines()`方法将冗长的字符串转换为一系列行，其会返回一个列表，包含文件中所有行。例如：
~~~python
from pathlib import Path

path = Path('data.txt')
contents = path.read_text()

lines = contents.splitlines()
for line in lines:
    print(line)
~~~

运行结果如上。

​    当将文件的内容从磁盘上读到内存中后，就可以对数据进行任意操作了。

> [!WARNING]
>
> 在读取文本文件时，python将其中的所有文本都解释为字符串。如果想要读取数，则需要使用函数`int()`或者`float()`来将其转换为数。

### 读出字节

   除了读出文本，还可以用方法`read_bytes()`读出字节，以`data.txt`文件为例，我们将文件中内容修改为：
~~~text
Hello World.
~~~

已知一个字符占一个字节，因此我们尝试读出字节内容：
~~~python
from pathlib import Path

path = Path('data.txt')
contents = path.read_bytes()
print(contents)
~~~

运行结果：
~~~bash
b'Hello World.'
~~~

### 确认文件存在

​    假设需要事先确定 **指定路径下的文件是否存在** ，则可以使用`exist()`方法来确定，若文件存在则返回`True`，否则返回`False`:
~~~python
from pathlib import Path

path = Path('nofiles')
if path.exists():
    print('Found such file')
else:
    print('No such file')
~~~

运行结果视文件`nofile`是否于该程序文件存在于同一目录下。

## 写入文件

### 写入文本 

​    在确定了一个文件的路径后，可以尝试使用`write_text()`方法来向文件里写入数据，例如写入一行：

~~~python
from pathlib import Path

path = Path('data.txt')
path.write_text('Python Programming.')
~~~

运行结果如下，打开data.txt文件：
~~~text
Python Programming.
~~~

> [!WARNING]
>
> Python只支持将字符串写入文本文件，如果需要写入数，则需要使用`str()`转换为字符串。
>
> 且需要注意使用`write_text()`方法不会保留原来文件的内容，会直接覆盖源文件的内容，导致源文件数据丢失。

如果需要写入多行数据，则需要使用在每一行字符串后加入换行符`\n`，在使用方法`write_text()`方法写入。

### 写入字节

​    当然可以通过`write_bytes()`方法写入字节，例如：
~~~python
from pathlib import Path

num = 200
path = Path('data.txt')
path.write_bytes(num.to_bytes())
~~~

此时打开文件应该会看到一个乱码`�`,这是很正常的，因为上述操作是将数据转换为字节数据写入文件，文本文件按字节值尝试解析字符，假设对应字节值没有正确对应字符，则会显示乱码。

如果我们此时按字节读出文件内容:
~~~python
from pathlib import Path

num = 200
path = Path('data.txt')
path.write_bytes(num.to_bytes())
contents = path.read_bytes()
print(int.from_bytes(contents))
~~~

运行结果如下：

~~~bash
200
~~~

### with关键字

在Python编程中，资源管理是一个重要但容易被忽视的环节。`with` 关键字为我们提供了一种优雅的方式来处理文件操作、数据库连接等需要明确释放资源的场景。

with 是 Python 中的一个关键字，用于 **上下文管理协议（Context Management Protocol）** 。它简化了资源管理代码，特别是那些需要明确释放或清理的资源（如文件、网络连接、数据库连接等）。

例如：
~~~python
with open('data.txt', 'r') as file:
    content = file.read()
    print(content)
# 文件已自动关闭
~~~

其中`open()`函数用法和C语言中的`fopen()`函数用法类似，这里不再赘述。

假设不使用`with`语句，上述代码就需要写成：
~~~python
file = open('data.txt', 'r')
content = file.read()
print(content)
file.close()
~~~

## 异常

​    有时候运行python程序会产生错误，例如运行以下程序：
~~~python
print(19/0)
~~~

会发生除0错误：
~~~bash
Traceback (most recent call last):
   line 1, in <module>
    print(19/0)
          ~~^~
ZeroDivisionError: division by zero
~~~

可以看到产生了一个异常对象`ZeroDivisionError`,假设我们此时使用异常机制来捕获这个异常对象，就可以针对这个异常进行处理。使用`try-except`结构可以捕获python中的异常，以上面的例子为例：
~~~python
try:
    print(19/0)
except ZeroDivisionError:
    print('You can\'t divide by zero.')
~~~

运行结果如下：
~~~bash
You can't divide by zero.
~~~

当然可以使用`else`代码块来包含 **没有异常时成功执行的代码** ，例如：
~~~python
while True:
    fnum = input("\nEnter first number:")
    if fnum == 'quit':
        break
    snum = input("\nEnter second number:")
    if snum == 'quit':
        break
    try:
        answer = int(fnum)/int(snum)
    except ZeroDivisionError:
        print('You can\'t divide by zero.')
    else:
        print(answer)
~~~

运行结果如下：
~~~bash

Enter first number:10 

Enter second number:0
You can't divide by zero.

Enter first number:12

Enter second number:3
4.0

Enter first number:quit
~~~

可以看到程序不会因为异常而导致程序崩溃了，即使代码产生了异常，只要被捕获并正确处理了，程序就不会因此异常退出（处理代码主动触发的退出除外）。

也可以使用`finally`代码块来包含 **不论异常是否发生都一定会执行的代码** ，例如：

~~~python
def division(fnum,snum):
    try:
        answer = int(fnum)/int(snum)
        return answer
    except ZeroDivisionError:
        print('You can\'t divide by zero.')
    finally:
        return -1
    
an1 = division(19,0)
an2 = division(12,3)
print(an1,an2)
~~~

运行结果如下：
~~~bash
You can't divide by zero.
-1 -1
~~~

可以看到不论`try`代码块中是否发生异常，`finally`代码块中的`return`语句始终会返回-1值。

如果你需要在 **异常产生时不做任何处理** ，可以使用`pass`语句，例如：
~~~python
try:
    file = open('nofile','r')
except FileNotFoundError:
    pass
else:
    file.close()
~~~

如果你运行上面的程序，只要保证文件`nofile`不存在于同一目录下，程序不会有任何输出。假设对于某个异常暂时不知道怎么进行处理，也可以使用`pass`语句来充当占位符的作用。

## Json数据存储

​    json文件可以很方便地按照结构存储数据，python中存在模块可以将python数据结构转换为json格式的字符串。

​    下面的程序用于存储一组数，首先可以使用`json.dumps()`方法存储这组数，然后使用`json.loads()`来读取这组数。前者接受一个参数，会返回一个json格式的字符串，例如：
~~~python
from pathlib import Path
import json

numbers = [2,3,4,6,11,32]

path = Path('numbers.json')
contents = json.dumps(numbers)
path.write_text(contents)
~~~

此时打开`numbers.json`文件，可以看到其中的内容：
~~~json
[2, 3, 4, 6, 11, 32]
~~~

接着我们尝试读入数据：
~~~python
from pathlib import Path
import json

path = Path('numbers.json')
contents = path.read_text()
numbers = json.loads(contents)

print(numbers)
~~~

运行结果如下：
~~~bash
[2, 3, 4, 6, 11, 32]
~~~

# C++中的左值引用

​    首先我们需要知道什么是 **复合类型** ，复合类型是基于其他类型定义的类型，其中 **指针、引用** 是非常经典的复合类型。

​    C++中的指针和C语言中区别并不大，但需要注意的是C++中针对空指针新设立了一个`nullptr`（C++11新增），与C语言中的`NULL`明面上区别并不是很大，所以不用特别在意。

​    **引用（reference）** 为对象起了另一个名字，引用类型引用另一种类型，其定义形式如下所示：

~~~C++
int val = 512;
int &refval = val;
~~~

> [!WARNING]
>
> 需要注意，对引用进行定义时， **必须要进行初始化** ，否则会报错。
>
> 同时，C++11中新增了一种引用：右值引用（rvalue reference），关于右值引用在后续会进行详细介绍，这种引用主要是用于 **内置类** ，在这里提及的“引用”一般是指的 **左值引用（lvalue reference）**。

当定义完成后，引用和其定义值会被一直绑定在一起，且无法令引用重新绑定到另外一个对象。可以简单理解为C语言中的指针常量。

​    引用一定程度上可以理解为已存在对象的另一个名字，如果在定义引用后尝试对引用进行更改，被绑定的对象也会发生变化，与指针的情况类似，例如：
~~~C++
#include<iostream>
using namespace std;

int main(){
    int val = 10;
    int &relval = val;
    relval = 1024;
    cout<<val<<endl;
}
~~~

运行结果如下：
~~~bash
1024
~~~

>[!WARNING]
>
>引用只能用于绑定符合类型的对象，当绑定 **不符合类型的对象、常量、另一个引用** 时会发生报错，例如下面就是非法的引用：
>~~~c++
>int &refval1 = 10; // error: 引用类型的初始值必须是一个对象
>
>double val = 20.26; 
>int &refval2 = val; //error：此处引用类型的初始值必须是int类型对象
>
>double &refval = val;
>double &refval3 = refval; //error: 无法引用引用
>~~~

​    引用本身不是一个对象，因此 **不能定义指向引用的指针** 。但是指针是对象，可以定义 **对指针的引用** ，例如：
~~~c++
#include<iostream>
using namespace std;

int a = 1024;
int *p = nullptr;
int *&rp = p;

int main(){
    rp = &a; //通过引用rp将指针p指向变量a的内存
    cout<<*rp<<endl;
    *rp = 2048; //通过引用rp修改指针p指向的变量a的值
    cout<<*rp<<endl;
}
~~~

运行结果如下：
~~~bash
1024
2048
~~~

上述内容可能比较难以理解，但是只要多实践就很容易理解。

---

引用在C++作用比较大，在某些场景下可以代替复杂的指针操作，例如给函数传递实参地址的时候就可以将指针参数替换为引用参数，就可以按照形参的使用形式去修改实参的内容。请读者自行尝试。

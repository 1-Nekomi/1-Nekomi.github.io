# 新增类型

C++相对于C有一些新增数据类型，以后有增加的都在这里一并举出并说明：

|  类型名  |            意义            |
| :------: | :------------------------: |
| wchar_t  | 基本数据类型——双字节字符型 |
|   bool   |  基本数据类型——布尔逻辑型  |
|  class   |     非基本数据类型——类     |
| char16_t |   Unicode字符，占两字节    |
| char32_t |   Unicode字符，占四字节    |

同时你可以尝试回忆C语言的基本数据类型和非基本数据类型有哪些。回忆不起来的话请看《C++程序设计教程（第3版）》P15查阅。

​	同时注意：**short只能修饰int，long只能修饰int和double，unsigned和signed只能修饰char和int**。

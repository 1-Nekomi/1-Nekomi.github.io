# C++中的关键字和操作符替代名

## 操作符替代名

C++为某些标点符号定义了替代拼写形式，作为关键字存在于语言中，这些替代名在C++98/03标准中就已存在。

| 替代名（关键字） | 对应的标点操作符 | 含义         |
| :--------------- | :--------------- | :----------- |
| `and`            | `&&`             | 逻辑与       |
| `and_eq`         | `&=`             | 按位与赋值   |
| `bitand`         | `&`              | 按位与       |
| `bitor`          | `|`              | 按位或       |
| `compl`          | `~`              | 按位取反     |
| `not`            | `!`              | 逻辑非       |
| `not_eq`         | `!=`             | 不等于       |
| `or`             | `||`             | 逻辑或       |
| `or_eq`          | `|=`             | 按位或赋值   |
| `xor`            | `^`              | 按位异或     |
| `xor_eq`         | `^=`             | 按位异或赋值 |

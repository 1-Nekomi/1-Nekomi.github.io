# 函数

​	这里默认学习了C的函数，对基本概念就不赘述了。

​	函数的调用实际上是利用了栈，**先调用的先进栈**，然后函数调用内存占用分为以下几个板块：

|                           形式参数                           |
| :----------------------------------------------------------: |
|                           **参数**                           |
|                         **返回地址**                         |
| **调用函数运行状态**（若为main函数则为**操作系统运行状态**） |

函数类型可以笼统地分为以下几种：**普通函数，递归函数、内联函数、重载函数、默认参数的函数**，重点介绍后四者。

## 递归函数

​	递归的含义顾名思义就是**函数自己调用自己**，分为*直接调用* 和*间接调用* 两种。请思考下面代码相对应的形式是哪种：

```c++
void fun1(){
    if(...)
        fun1();
    ...
}//代码1
```

 ~~~c++
 void fun1(){
     if(...)
         fun2();
 }
 
 void fun2(){
     if(...)
         fun1();
 }//代码2
 ~~~

使用递归时需要注意：

​	递归使用必须有条件，也就是必须存在能够退出递归的语句。否则会无止境地调用函数直到栈溢出。例如下面这个代码就是错误的：

```c++
void fun1(int num){
    fun(num-1);
    if(num>1)
        cout<<"OK,Fine"<<endl;
}
```

​	递归在处理某些数据项的情况下能保证代码的整洁性和可读性，但是当数据项过大的时候，*函数调用占用的内存会过多*，而且*系统处理函数调用也需要时间*，这就导致了过多的调用会存在一些不必要的内存和时间开销。因此对于一些数据项可以尝试*消去递归* 采用简单的循环代替。

## 内联函数

​	又称内嵌函数，用于提高程序的运行效率。

​	函数的调用需要建立栈内存环境，需要一定的内存和时间开销。假设存在一个函数内存简单，但调用次数多，内存方面不需要担心太多，因为函数调用完成后会释放内存。但是**时间开销是无法挽回的**，这一定程度上导致了程序运行效率较低。

​	例如：

```c++
#include<iostream>
using namespace std;

int isnumber(char);

int main(){
    char c;
    while((c = cin.get()) != '\n'){
        if(isnumber(c))
            cout<<"You inputed a digit."<<endl;
        else
            cout<<"You inputed a non_digit."<<endl;
    }
    return 0;
}
int isnumber(char c){
    return (c >='0' && ch<= '9')? 1:0;
}
```

当然也可以将isnumber函数中的条件运算符等价替换：

```c++
...
	if((c>='0' && c<='9')? 1:0)
...
```

但是这种形式增加了程序复杂度，不利于阅读，为了方便阅读，就需要**声明内联函数**。

​	声明关键字为**inline**，例如：

```c++
inline int isnumber(char);
```

作用是**声明这个函数后，系统会先创建一段代码，系统每次遇到这个函数调用会直接将这段代码来替换调用**。一定程度上和define有些类似，注意区分：

```c++
#define Max(x,y) ((x)<(y)? (x):(y))
inline int Max(int x,int y){
	return x<y? x:y;
}
```

​	但是**使用宏定义无法进行语法检查**，一定程度上会产生无法想象的错误。

使用内联函数需要注意：

①内联函数必须先声明inline后再调用，不能只在定义时声明inline，否则会被视为普通函数。例如：

```c++
int isnumber(char);

inline int isnumber(char c){
    ...
}//会被视为普通函数
```

②被声明为内联函数的函数结构不能含有switch、if-else、while等复杂结构控制语句，否则会被视为普通函数。

③递归函数无法被声明为内联函数。

## 重载函数

​	我们都知道在C中，函数名字必须唯一，这也导致了一些函数定义上的麻烦，例如，要求一个数的绝对值，在C中只能这样定义：

```c
int fabs(int);
double d_fabs(double);
float f_fabs(float);
long L_fabs(long);
```

这样调用函数时可能会产生一些不便。C++支持重载函数，意思是**保证函数参数表不一致的情况下重用函数名**，例如上面这些函数定义在C++里面就可以改成这样：

```c++
int fabs(int);
double fabs(double);
float fabs(float);
long fabs(long);
```

注意，当重载函数的参数表一致时会报错，例如下面声明会报错：

```c++
float fun(double);
double fun(double);
```

因此重载函数至少要**保证参数表中参数个数、类型、顺序其中一个不一致**。

​	这样本质相同的函数能够使用同一个名字，同时也能够处理不同类型的数据。那么系统是如何知道如何调用哪个重载函数的呢？这是存在一个寻找顺序的：

​	①寻找一个**参数表数据类型严格对应**的匹配，若没找到进行下一步；

​	②通过**参数表数据类型转换**（转换优先级详见“算术类型转换”）寻找一个匹配，若没找到进行下一步；

​	③通过**用户定义的转换**寻找一个匹配，若只能找到一个重载函数，就调用那一个。

例如：

```c++
void print(double);//函数
void print(int);//重载函数1

void func(){
    print(1);//调用重载函数1
    print(1.0);//调用函数
    print('a');//调用重载函数1
    print(3.1415926);//调用函数
}
```

关于第三步涉及到了后增量函数type operator ++ (type&,int)，这里暂时不介绍。

如果上述三步都失败了，则会以报错处理：

```c++
void fun(double);
void fun(long);

void FUN(int a){
    fun(a);
}
```

由于double、long不能通过转换变成int类型，因此找不到对应匹配的参数表，会以“二义性”编译报错。

​	重载函数最好保证实现的都是同一个功能，不然会破坏可读性。

## 默认参数的函数

​	C++可以在函数声明时给参数表中的参数一个默认值，这样做的好处是：不传递参数给函数时，函数能按照默认值进行工作。例如：

```c++
void fun(int loops = 1000);

void FUN(){
    fun(2500);
    fun();
}
```

​	这样在有参数传递的情况下函数按照形参值工作，没有参数传递时则按照设置的默认值工作。

注意：

①**函数默认值设立只有在声明时才能进行**，定义时是无法进行的，除非没有函数声明语句。

②如果一个函数中有多个默认参数，则形参分布中**默认参数必须从右到左逐渐定义**，不能中间穿插无默认参数，调用函数时，**只能向左匹配参数**。例如：

```c++
void func(int a = 1,int b ,int c =3);//错误的
void func(int a,int b =2,int c = 3);//正确的

void FUN(){
    func(1,2);//传递1给a，传递2给b，c默认为3。
}
```

③默认参数设置尽量避免和重载函数混合使用，因为很大可能会产生二义性。例如：

```c++
void func(int);
void func(int,int = 8);
void func(int,int = 3,int = 4);

void FUN(){
    fun(5);//不知道调用三个函数中的哪个
    fun(10,20);//不知道调用两个重载函数中的哪一个
}
```

​	当然合理利用默认参数能让一组重载函数合多为一：

```c++
void func(int,int = 4){...}
void func(int a){return func(a,5);}
void func(){return func(3,4);}

void func(int a){return func(a);}//错误的
void func(){return func(3);}//错误的
```

后面两句是错的，请尝试思考为什么。（提示：函数递归）

④默认值的限定域很广，值，表达式，也可以是函数，例如：

```c++
int a = 1;
int fun(int);
int g(int x = fun(a));
```

但默认值不能是**局部变量**，可以是**全局变量、全局常量**。

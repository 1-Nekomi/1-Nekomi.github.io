# 条件运算符和逗号表达式

## 条件运算符

​	一般形式：

````c++
(表达式)?(为真的输出结果):(为假的输出);
````

​	在C/C++中条件运算符运用可以代替简单的if-else结构，例如：

```c++
cout<<(a<b?"Hello":"World")<<endl;
```

同时在C++中，条件运算符还可以作为左值组成表达式，可以改变其中对象的值。例如：

```c++
int a = 20,b =10;
(a<b?a:b) = 1;
cout<<a<<endl
    <<b<<endl;
```

可以观察到b的值被改变了。

​	注意：**在C中条件运算符是不能作为左值的**，这属于C++的拓展功能。

## 逗号表达式

​	一般形式：
```c++
表达式1,表达式2,表达式3,···,表达式n
```

C/C++会按照顺序对表达式进行计算，例如：

```c++
int a,b,c;
cout<<(a = 1,b = a+2,c = b+3)<<endl;
```

输出结果为6。

​	逗号表达式还可以用于**函数调用的参数传递**。例如：

```c++
func((j = 1,j+3));
```

这样就将j = 4传递给了func函数。

# 指定字面值的类型

​    在C++的常量中，存在一些前缀或者后缀能够改变整型、浮点数、字符型字面值的默认类型。

## 整型

|     后缀     | 最小匹配类型 |
| :----------: | :----------: |
|  `u` or `U`  |  `unsigned`  |
|  `l` or `L`  |    `long`    |
| `ll` or `LL` | `long long`  |

例如：
~~~c++
42ULL //无符号整型字面量，类型是unsigned long long
~~~

## 浮点数

|    后缀    |     类型      |
| :--------: | :-----------: |
| `f` or `F` |    `float`    |
| `l` or `L` | `long double` |

例如：
~~~c++
1E-3F //单精度浮点型字面量，类型是float
3.1415926L //扩展精度浮点型字面值，类型是long double
~~~

## 字符型字面量

| 前缀 |              含义               |    类型    |
| :--: | :-----------------------------: | :--------: |
| `u`  |         Unicode 16字符          | `char16_t` |
| `U`  |         Unicode 32字符          | `char32_t` |
| `L`  |             宽字符              | `wchar_t`  |
| `u8` | UTF-8（仅适用于字符串字面常量） |   `char`   |

例如:
~~~c++
L'a' //宽字符型字面量，类型是wchar_t
u8"hi!" //utf-8字符串字面量（8位编码一个Unicode字符）
~~~

> [!WARNING]
>
> 对于 **字符型字面量** 只适用于前缀，对于 **整型、浮点数** 只适用于后缀。

# 函数形参

​    函数形参在C语言中是一个比较常见的概念，因此这里不再赘述概念相关的内容，而是根据C语言，补全C++中的一些用法。

## main函数的形参

​    main函数的形参在C语言中的表现形式和C++中一致，主要是用于处理命令行传递的参数，接受命令行参数的main函数声明形式一般如下：
~~~c++
int main(int argc,char** argv){
    statements
}
~~~

其中形参`argc`表示命令行参数的数量，`argv`表示命令行参数的具体内容。以下面的程序示例：
~~~C++
#include<iostream>
using namespace std;

int main(int argc,char** argv){
    for(int i=0;i<argc;i++)
            cout<<argv[i]<<endl;
    
    return 0;
}
~~~

将上述程序编译成名为`MyProject`的二进制程序后运行，结果如下：
~~~bash
$ ./MyProject  -a --prog Hello
./MyProject
-a
--prog
Hello
~~~

可以看到对于 **索引为0的参数为项目名本身，从索引1开始往后就是传递给程序的参数** 。

## 含可变形参的函数

​    有时候我们无法预测需要传递几个实参，为了解决这个问题，C++11提供了三种方式：

- 如果所有实参类型相同，则可以使用 **`initializer_list`标准库类型**
- 如果存在实参类型不同，则可以使用 **可变参数模板**
- 对于C语言函数，可以使用 **省略符形参**

这里只介绍第一、三种方式，对于可变参数模板，会在后续介绍模板的过程中涉及。

### initializer_list类型

​    该类型一般用于表示某种特定类型的数组，其定义位于同名的头文件中，该类型提供的操作有以下几种：
|                操作                 |                             含义                             |
| :---------------------------------: | :----------------------------------------------------------: |
|      `initializer_list<T> lst`      |                 默认初始化T类型元素的空列表                  |
| `initializer_list<T> lst{a,b,c...}` | 直接初始化给定初始值数量和特定值的列表。 **列表中元素为常量** |
|             `lst2(lst)`             | 拷贝或赋值一个initializer_list对象，不会拷贝列表中的元素， **拷贝后原始列表和副本共享元素** |
|            `lst2 = lst`             |                             同上                             |
|            `lst.size()`             |                     获取列表中的元素个数                     |
|            `lst.begin()`            |                  返回指向lst中首元素的指针                   |
|             `lst.end()`             |              返回指向lst中尾元素下一位置的指针               |

可以看出`initializer_list`也是一个模板类型，目前我们只需要知道如何使用它即可。

> [!TIP]
>
> initializer_list对象中的所有元素均为常量。

下面是一个简单的示例程序，说明该类型如何作为函数形参的：
~~~c++
#include<iostream>
#include<initializer_list>
#include<string>
using namespace std;

void PrintName(initializer_list<string> name){
    for(string n : name)
        cout<< n << endl;
}

int main(int argc,char** argv){
    PrintName({"Nike","John","Jack"});

    return 0;
}
~~~

运行结果如下：
~~~bash
Nike
John
Jack

~~~

> [!NOTE]
>
> 当一个函数的形参列表包含initializer_list类型时，传递该类型字面量实参需要使用花括号`{}`来包含参数列表。对于其他类模板不适用。

> [!WARNING]
>
> 需要注意的是，initializer_list对象之间不会产生拷贝行为，这意味着 **原列表和副本都共享同一份元素** ，但也不需要担心误改导致的异常，因为initializer_list对象中的元素是常量，无法被修改。

### 省略符形参

​    这类形参一般只是用于方便C++访问C代码而设置的，大多数类类型的对象在传递给省略符形参的时候都无法正确被拷贝，因此在C++代码中不推荐使用。

​    使用省略符形参需要配合C语言标准库`stdarg.h`，其中定义了一组宏用于安全地遍历可变参数：

| 宏/类型              | 作用                                                         |
| :------------------- | :----------------------------------------------------------- |
| `va_list`            | 定义一个变量，用于存储参数列表的状态。                       |
| `va_start(ap, last)` | 初始化 `va_list` 变量 `ap`，`last` 是省略符前最后一个固定参数的名称。 |
| `va_arg(ap, type)`   | 按类型 `type` 取出当前参数，并自动将内部指针移动到下一个参数。 |
| `va_end(ap)`         | 清理 `va_list` 变量，结束可变参数的遍历。                    |

> [!WARNING]
>
> - **类型安全缺失**：编译器不会检查可变参数的实际类型，调用者必须保证传递的类型与 `va_arg` 中指定的类型一致，否则行为未定义。
> - **无法获取参数个数**：函数内部不知道究竟传入了多少个参数，因此通常需要**显式**传递个数（如 `count`）或用某种终止标记（如 `printf` 用格式字符串中的 `%` 数量）。
> - **默认实参提升**：在调用可变参数函数时，`float` 会被提升为 `double`，`char`/`short` 会被提升为 `int`（或 `unsigned int`），所以 `va_arg` 中不应使用 `float`、`char`、`short`，而应使用提升后的类型。

下面是一个简单的示例程序：

~~~C
#include <stdio.h>
#include <stdarg.h>

// 计算 num 个整数的和
int sum(int num, ...){
    int total = 0;
    va_list args;                 // 声明一个 va_list 变量
    va_start(args, num);          // 初始化，指向第一个可变参数

    for (int i = 0; i < num; i++) {
        total += va_arg(args, int); // 取出一个 int 类型参数
    }

    va_end(args);                 // 清理
    return total;
}

int main(){
    printf("1 + 2 + 3 = %d\n", sum(3, 1, 2, 3));
    printf("10 + 20 + 30 + 40 = %d\n", sum(4, 10, 20, 30, 40));
    printf("空参数求和 = %d\n", sum(0));  // 0 个参数，合法

    return 0;
}
~~~

运行结果如下：
~~~bash
1 + 2 + 3 = 6
10 + 20 + 30 + 40 = 100
空参数求和 = 0

~~~

---

​    在上述内容中，如果需要编写命令行工具，则需要着重关注main函数的形参；如果需要传递同类型可变形参，则可以参考initializer_list类型；对于省略号形参一般是用于C语言中，例如printf、scanf等经典函数都使用了省略号形参，在C++中由于兼容问题并不推荐使用。

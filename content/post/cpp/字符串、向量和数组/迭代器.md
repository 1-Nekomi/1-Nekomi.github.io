# 迭代器

​    虽然可以使用下标运算符来访问一些对象容器或者数组中的元素，但在后续接触到其他类型的容器时，有些标准库容器并不支持使用下标运算符来访问容器中的元素，但所有标准库容器都支持使用 **迭代器（inerator）** 来访问容器中的元素。且部分对象数据类型也有很多与容器类型相似的操作，也需要迭代器来辅助完成。

​    同样的，类似于指针类型，迭代器也提供了对对象的间接访问，也分为有效迭代器和无效迭代器，判定标准与指针类似，这里不再赘述。

## 使用迭代器

​    在使用迭代器的时候，一般比较难判定迭代器的具体数据类型，也并不需要在意，可以使用`auto`关键字让编译器自行推理即可。

​    和指针不一样的是，获取迭代器不是使用取址运算符，而是依靠具有迭代器的数据类型中的函数成员返回对应类型的迭代器，例如`begin()`和`end()`依次返回 **头元素** 和 **尾元素的下一位置** ，例如：
~~~c++
#include<iostream>
#include<string>
using namespace std;

int main(){
    string s("Hello,World");
    auto a = s.begin();
    auto b = s.end();
    
    cout<< *a << *(b-1) <<endl;
    
    return 0;
}
~~~

运行结果如下：
~~~bash
Hd
~~~

从上述例子来看，`end()`成员返回的是尾元素下一位置，如果不加以限制则可能指向一个无效（不存在）元素。这种迭代器一般称为 **尾后迭代器（off-the-end iterator）** ，这种迭代器主要是用于表示已经处理完了容器中所有元素。

> [!TIP]
>
> 若容器为空，则`begin()`与`end()`返回的是同一位置的迭代器。

### 迭代器运算符

​    在使用迭代器的过程中可能会涉及到迭代器相关的运算，主要的标准容器迭代器的运算符如下表所示：

|   运算符    | 含义 |
| :---------: | :--: |
|   `*iter`   | 返回迭代器所指元素的 **引用** |
| `iter->mem` | 解引用iter并获取该元素的名为mem的成员，等价于`(*iter).mem` |
|  `++iter`   | 令iter指向容器的下一个元素 |
|   `--iter`   | 令iter指向容器的上一个元素 |
|     `iter1 == iter2`     | 比较两个迭代器是否相同。只当两个迭代器 **指向同一个元素或者是同一个容器的尾后迭代器** 时，两者相等。 |
| `iter1 != iter2` | 比较两个迭代器是否不等。不等条件为上行的取反。 |

可以看到迭代器大部分运算都和指针类似，但存在部分差异，例如对指针解引用不会返回元素的引用，而是元素本身，不过在具体编程过程中可以忽略这个问题。

下面的程序尽可能覆盖了上述所有操作：
~~~c++
#include<iostream>
#include<vector>
#include<string>
using namespace std;

int main(){
    vector<string> v{"Hello","World"};
    auto vb = v.begin(),ve = v.end();
    if(vb != ve){ //判定容器是否为空
        ve--;
        cout << *vb <<endl;
        if(!ve->empty()){ //判定是否是空串
            cout << *ve;
        }
    }
    
	return 0;   
}
~~~

运行结果如下：
~~~bash
Hello
World
~~~

### 迭代器类型

​    虽然说迭代器类型比较难确定，但不代表其没有数据类型。拥有迭代器的标准库类型使用`iterator`和`const_iterator`来表示迭代器的类型，例如：
~~~c++
vector<int>::iterator it1;
string::iterator it2;

vector<int>::const_iterator it3;
string::const_iterator it4;
~~~

对于类型为`iterator`的迭代器，可以读写对应容器的元素；对于类型为`const_iterator`的迭代器，只能读对应容器中的元素。

> [!TIP]
>
> 与此同时，对于函数`begin()`和`end()`，假设对象是常量，则返回`const_iterator`迭代器类型，否则返回`iterator`。
>
> 当然，如果实在需要`const_iterator`迭代器类型，可以使用函数`cbegin()`和`cend()`来无视对象的常量属性，始终返回迭代器常量数据类型。

## 迭代器运算

​    对于某些特殊的容器，例如vector和string，迭代器运算除了上述提到的通用运算以外，还有一些额外的运算，如下表所示：

|      运算       |                             含义                             |
| :-------------: | :----------------------------------------------------------: |
|   `iter + n`    |              移动迭代器到后n个元素上，属于右值               |
|   `iter - n`    |              移动迭代器到前n个元素上，属于右值               |
|  `iter1 += n`   |                    加法复合语句，属于左值                    |
|  `iter1 -= n`   |                    减法复合语句，属于左值                    |
| `iter1 - iter2` | 迭代器减法，返回两个迭代器之间的距离，参与该迭代器运算的两个迭代器必须指向同一个容器中的元素或者尾元素的下一位置 |
| `>、>=、<、<=`  | 迭代器关系运算符，主要是比较迭代器之间的位置关系，位置越靠后的越大。参与该迭代器运算的两个迭代器必须指向同一个容器中的元素或者尾元素的下一位置 |

例如下面的代码尽可能涉及到了上面大部分运算：
~~~c++
#include<iostream>
#include<vector>
#include<string>
using namespace std;

int main(){
    vector<string> v{"Hello"," ","World","!","John","."};
    auto vb = v.begin(),ve = v.end();
    
    cout << *(vb+4) <<endl;
    cout << *(ve-=1) <<endl;
    cout << vb-ve <<endl;
    cout << (vb<ve?true:false);
    
    return 0;
}
~~~

运行结果如下：
~~~bash
John
.
-5
1
~~~

可以自行推理上述代码的结果是怎么出来的。同时上述迭代器的运算还可以用于实现 **二分算法** ，请读者自行实现，相关算法原理详见《数据结构》或《算法设计与分析》。

---

可以看到迭代器的很多操作都与指针类似，因此只要将其与指针进行类比学习就不会觉得有多复杂了。

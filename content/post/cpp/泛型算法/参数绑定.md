# 参数绑定

​    在之前我们接触了其中用于处理谓词参数限制问题的方法之一：lambda表达式，除此之外还有 **参数绑定** 这种方法，尤其是面对函数体语句较为复杂的情况，使用参数绑定会比lambda表达式更好。

​    为了方便讲解，还是使用原来的例子，如下所示：
~~~c++
#include<iostream>
#include<vector>
#include<string>
#include<algorithm>

using namespace std;

//找到第一个符合长度len的字符串s
bool simple(string s,int len){
    return s.size() == len;
}

int main(){
    vector<string> ls{"Hello","World"};
    auto it = find_if(ls.begin(),ls.end(),simple);

    cout<< *it;
    return 0;
}
~~~

## 标准库bind函数、ref函数

​    为了能够向simple函数传递参数len，可以使用标准库bind函数，其声明位于头文件`functional`中。可以将bind函数视作一个通用的函数适配器，其接受一个可调用对象，返回一个新的可调用对象来适应需要，其使用形式如下：
~~~c++
auto newCall = bind(call,arg_list);
~~~

其中`newCall`本身就是一个可调用对象，`arg_list`是一个用逗号分隔的参数列表，对应给定的`call`对象的参数。当我们尝试调用`newCall`时，会将`arg_list`中的参数传递给`call`函数。

在`arg_list`中可能会出现形如`_n`这样形式的参数名，其中`n`是一个整数，这个参数主要起到了一个 **占位符** 的作用，表示`newCall`的参数，占据了传递给`newCall`参数的位置。该参数位于标准命名空间`std`的`placeholders`空间中。

以上面的代码片段为例使用bind函数：

~~~c++
#include<iostream>
#include<vector>
#include<string>
#include<functional>
#include<algorithm>

using namespace std;

//找到第一个符合长度len的字符串s
bool simple(string s,int len){
    return s.size() == len;
}

int main(){
    vector<string> ls{"Hello","World"};
    //绑定另一个参数5到newsimple，同时使用_1表示newsimple只接受一个参数
    auto newsimple = bind(simple, placeholders::_1 , 5);
    auto it = find_if(ls.begin(),ls.end(),newsimple);

    cout<< *it;
    return 0;
}
~~~

运行结果为：
~~~bash
Hello
~~~

需要注意的是，对于`newsimple`函数，假设其接受两个参数，则需要在参数列表中的两个位置使用`_n`参数作为占位符，其他情况以此类推。但是对占位符的顺序并没有严格要求，甚至基于这个特性我们甚至可以重排原来函数的参数顺序，例如对于一个函数：
~~~c++
int function(a,b,c,d);
auto _function_ = bind(function,1024,_2,2048,_1);
~~~

此时的`_function_`实际上声明为`int _function_(_1,_2);`，对其调用会被映射成`function(1024,_2,2048,_1)`。

> [!TIP]
>
> 当然，bind函数中的可调用对象也可以是一个lambda表达式，同样以上面的程序为例：
> ~~~c++
> #include<iostream>
> #include<vector>
> #include<string>
> #include<functional>
> #include<algorithm>
> 
> using namespace std;
> 
> int main(){
>     vector<string> ls{"Hello","World"};
>     //绑定另一个参数5到newsimple，同时使用_1表示newsimple只接受一个参数
>     auto newsimple = bind([](const string &s , int len){
>         return s.size() == len;
>     }, placeholders::_1 , 5);
>     auto it = find_if(ls.begin(),ls.end(),newsimple);
> 
>     cout<< *it;
>     return 0;
> }
> ~~~

上述例子只涉及了值绑定，涉及到引用绑定则完全不一样了，以下面的程序为例：
~~~c++
#include<iostream>
#include<vector>
#include<string>
#include<functional>
#include<algorithm>

using namespace std;

ostream& simple(ostream& os,const string &s){
    return os << s;
}

int main(){
    ostream& os = cout;
    vector<string> ls{"Hello","World"};
    
    auto newsimple = bind(simple,os,placeholders::_1);
    auto it = find_if(ls.begin(),ls.end(),newsimple);

    cout<< *it;
    return 0;
}
~~~

如果编译该程序则会在`find_if`的`newsimple`处产生报错，这是由于作为IO设施，`os`是无法被拷贝的，因此为了解决类似于这种 **传递无法拷贝参数的引用或者想要传递某些参数的引用** 的情况，则需要用到标准库函数`ref`函数，同样位于头文件`functional`中。上述程序正确写法如下：
~~~c++
#include<iostream>
#include<vector>
#include<string>
#include<functional>
#include<algorithm>

using namespace std;

ostream& simple(ostream& os,const string &s){
    return os << s;
}

int main(){
    ostream& os = cout;
    vector<string> ls{"Hello","World"};
    
    auto newsimple = bind(simple,ref(os),placeholders::_1);
    auto it = find_if(ls.begin(),ls.end(),newsimple);

    cout<< *it;
    return 0;
}
~~~

运行结果如下：
~~~bash
HelloHello
~~~

对于标准库函数`ref`，其返回一个对象，包含给定对象的引用，且该对象是可以拷贝的。除此之外，标准库中还有一个`cref`函数，用于生成一个`const`引用的对象。

---

因此为了解决谓词参数限制这个问题，我们现在有了两种解决方法：lambda表达式和参数绑定，如果函数体比较简单，则可以使用lambda表达式，如果函数体较为复杂，则最好使用参数绑定。

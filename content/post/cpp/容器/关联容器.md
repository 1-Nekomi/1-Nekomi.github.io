# 关联容器

​    在之前介绍顺序容器的时候，我们都知道顺序容器本质就是一种提供下标索引，然后获取对应位置的元素。但对于关联容器，我们可以只提供关键字，进而直接得到我们想要的元素。

​     关联容器的类型如下表所示：
|         类型         |                说明                 |
| :------------------: | :---------------------------------: |
|        `map`         | 关联数组的有序容器，保存关键字-值对 |
|        `set`         | 关键字即值，只保存关键字的有序容器  |
|      `multimap`      |        关键字可重复出现的map        |
|      `multiset`      |        关键字可重复出现的set        |
|   `unordered_map`    |     用哈希函数组织的无序集合map     |
|   `unordered_set`    |     用哈希函数组织的无序集合set     |
| `unordered_multimap` |     哈希组织且关键字可重复的map     |
| `unordered_multiset` |     哈希组织且关键字可重复的set     |

## 有序关联容器概述

### map

​    map有点类似于python中的字典结构，一个简单的例子如下所示：
~~~c++
#include<iostream>
#include<map>
#include<string>

using namespace std;
using telephone = string;
using name = string;

int main(){
    map<name, telephone> list;
    string word,telp;
    while(cin>>word>>telp){
        list[word] = telp;
    } 

    for(const auto &w : list){
        cout << w.first << ": " << w.second << endl;
    }
    return 0;
}
~~~

运行结果示例如下：
~~~bash
$ jack 123841
  nani 1234891234
jack: 123841
nani: 1234891234
~~~

在上述程序中可以看到索引值的时候我们并没有使用无符号数，而是使用了一个`string`对象去索引另一个`string`对象。

我们对map中的元素进行遍历时，会得到一个`pair`类型的对象，该类型是一个模板类型，保存两个公有数据成员：`first`和`second`，其中`first`代表关键字，`second`代表值。

   对于`map`类型，其初始化形式如下所示：
~~~c++
map<type1,type2> name = { {key1,val1},
                          {key2,val2}...};
~~~

其中的`{key,val}`共同构成一个元素，一个简单的例子如下所示：
~~~c++
map<string,string> list = { {"Jame","12233"},
                           	{"Jane","12814"},
                           	{"Charles","115324"}}
~~~

经过上述程序初始化后，`list`拥有三个元素。

需要注意的是对于`map`类型，所有的关键字都是不允许重复的，如果重复了，则会以第一个对应的键值对为准，例如：
~~~c++
#include<iostream>
#include<map>
#include<string>

using namespace std;

int main(){
    map<string,size_t> list = {
        {"jame",2},
        {"jame",3}
    };

    for(const auto& w : list )
        cout << w.first << " " << w.second << endl;

    return 0;
}
~~~

运行结果如下：
~~~bash
jame 2
~~~

对于`multimap`就没有这个限制，因此初始化的时候需要额外注意这一点。

### set

​    在set中关键字就是值本身，下面是一个简单的示例：
~~~c++
#include<iostream>
#include<map>
#include<set>
#include<string>

using namespace std;

int main(){
    map<string,size_t> list;
    set<string> exclude = {"The","But","And","Or","This"};

    string word;
    while(cin>>word){
        //若该单词不在需要排除的名单以外，则递增
        if(exclude.find(word) == exclude.end())
            list[word]++;
    }

    for(const auto& w : list){
        cout << w.first << " " << w.second << endl;
    }
    return 0;
}
~~~

运行结果示例如下：
~~~bash
$ The
  i
  om
  But
  And
  or
i 1
om 1
or 1
~~~

在上面的程序中，我们使用set来帮助我们来排除一些单词，但是由于在set中关键字就是值本身，因此我们 **无法通过索引来获取其中的元素** 。

### 类型别名

​    在有序关联容器中，有一些类型别名我们需要稍作了解，如下表所示：
|     类型      |                             说明                             |
| :-----------: | :----------------------------------------------------------: |
|  `key_type`   |                       容器的关键字类型                       |
| `mapped_type` |               关键字对应值类型，只适用于`map`                |
| `value_type`  | 对于`set`，等价于`key_type`<br />对于`map`，等价于`pair<const key_type,const mapped_type>` |

## pair类型

​    在上述遍历map容器的过程中，每个元素都被返回成了pair类型，该类型定义在utility头文件中。一个pair对象保存两个数据成员`first`和`second`，与容器类似，pair也是一个生成特定类型的模板，定义其对象时，必须提供两个类型名，不要求两个类型一样，例如：
~~~cpp
pair<string,string> a{"Jame","122341"};
pair<string,size_t> b;
pair<string,vector<string>> c;
~~~

如果不进行显式初始化，则对于数值类型会默认将其初始化为0，容器类型则会默认初始化为空容器。

### 操作

可以在pair类型对象上进行的操作如下表所示：
|            操作             |                             说明                             |
| :-------------------------: | :----------------------------------------------------------: |
|      `pair<T1,T2> p;`       |                     定义一个pair类型对象                     |
|   `pair<T1,T2> p(v1,v2)`    |           定义一个pair类型对象，并对其进行值初始化           |
|  `pair<T1,T2> p = {v1,v2}`  |          定义一个pair类型对象，并对其进行拷贝初始化          |
|     `make_pair(v1,v2)`      |              返回一个用v1和v2构造的pair类型对象              |
|          `p.first`          |                       返回p的first成员                       |
|         `p.second`          |                      返回p的second成员                       |
| `p1 < < | > | <= | >= > p2` | 按字典序进行比较。<br />例如`p1.first < p2.first`或者`p1.first > p2.first && p1.second < p2.second`时，`p1 < p2`成立。 |
|     `p1 < == | != > p2`     | 当first和second成员分别相等/存在一个不等时，p1和p2相等/不等  |

## 关联容器操作

### 添加元素

关联容器通常使用`insert`方法来向其中添加元素，其操作通常包含以下几种：

|                   操作                   |                             含义                             |
| :--------------------------------------: | :----------------------------------------------------------: |
|   `c.insert(v)`<br />`c.emplace(args)`   | 其中v是`value_type`类型对象；args是用于构造对象的参数<br />对于`map`和`set`，只有当容器中不存在对应的对象才会插入，函数返回一个`pair`类型对象，包含一个迭代器，指向具有指定关键字的对象，以及一个表示是否成功插入的bool值<br />对于`multimap`和`multiset`总会插入给定对象，并返回一个指向新元素的迭代器 |
|   `c.insert(b,e)`<br />`c.emplace(il)`   | 其中b和e均为迭代器，表示一个`c::value_type`类型值的范围；il是这种值的花括号列表<br />函数返回void |
| `c.insert(p,v)`<br />`c.empalce(p,args)` | p表示一个迭代器，v和args含义与上述无异<br />其中p的作用是向函数说明应该从哪个位置开始搜索新对象应该存储的位置<br />函数返回一个迭代器，指向具有给定关键字的元素 |

下面是一个简单的示例：
~~~c++
#include<iostream>
#include<map>
#include<set>
#include<utility>
#include<string>

int main(){
    std::map<std::string,int> m;
    std::set<std::string> s;
    
    //map插入操作
    m.insert({"word",1});
    m.insert(std::pair<std::string,int>("Look",3));
    m.insert(std::map<std::string,int>::value_type("See",4));
    m.emplace("Last",5);

    //set插入操作
    s.insert("word");

    //遍历map
    for(auto f : m){
        std::cout << f.first << " " << f.second << std::endl;
    }

    //遍历set
    for(auto f : s)
        std::cout << f << std::endl;

    return 0;
}
~~~

运行结果如下：
~~~bash
Last 5
Look 3
See 4
word 1
word
~~~

### 删除元素

关联容器有三个版本的`erase`函数来删除容器中的对象元素，如下表所示：
|      操作      |                             含义                             |
| :------------: | :----------------------------------------------------------: |
|  `c.erase(k)`  | 从c中删除 **每个** 关键字为k的元素，返回一个`size_type`值，表示删除的元素数量 |
|  `c.erase(p)`  | 从c中删除迭代器p指定的元素（p必须指向一个有效元素，且不能等于`c.end()`），返回一个指向p之后的元素的迭代器，若p指向尾元素，则返回`c.end()` |
| `c.erase(b,e)` |       从c中删除迭代器对b和e所表示的范围中的元素。返回e       |

下面是一个简单的示例程序：
~~~cpp
#include<iostream>
#include<map>
#include<string>

int main(){
    std::map<std::string,int> m{
        {"Jame",1},
        {"Look",2},
        {"See",3},
        {"Right",4}
    };

    m.erase("See");//删除指定关键字的元素

    for(auto f : m)
        std::cout << f.first << " " << f.second << std::endl ;
    std::cout << std::endl;

    m.erase(m.begin());//删除头元素

    for(auto f : m)
        std::cout << f.first << " " << f.second << std::endl;
    std::cout << std::endl;

    m.erase(m.begin(),m.end());//清空容器

    for(auto f : m)
        std::cout << f.first << " " << f.second << std::endl;
    std::cout << std::endl;

    return 0;
}
~~~

运行结果如下所示：
~~~bash
Look 2
Right 4

Look 2
Right 4


~~~

### map的下标操作

`map`和`unordered_map`容器重载了下标运算符和一个at函数，我们可以通过直接提供关键字来索引对应的值，但这里的下标索引和at函数和我们之前接触过的在数组上的使用略有不同，如下表说明所示：

|   操作    |                             说明                             |
| :-------: | :----------------------------------------------------------: |
|  `c[k]`   | 返回关键字为k的元素<br />若容器中不存在该元素，则添加一个关键字为k的元素，对其进行初始化 |
| `c.at(k)` | 访问关键字为k的元素<br />若容器中不存在该元素，则抛出`out_of_range`异常 |

例如：
~~~cpp
#include<iostream>
#include<map>
#include<string>

int main(){
    std::map<std::string,int> m{
        {"Jame",1},
        {"Look",2},
        {"See",3},
        {"Right",4}
    };

    std::cout << m["Look"] << std::endl;
    std::cout << m.at("Right") << std::endl;

    std::string s("Left");
    try{
        std::cout << m.at(s) << std::endl;
    }catch(std::out_of_range){
        std::cout << "Can't fine the key:" << s << std::endl;
    }

    m[s] = 5;//利用下标运算符插入元素
    std::cout << m.at(s) << std::endl;

    return 0;
}
~~~

运行结果如下：

~~~bash
2
4
Can't fine the key:Left
5
~~~

> [!TIP]
>
> 对一个map对象使用下标运算符返回的是`mapped_type`类型对象
> 对一个map对象迭代器进行解引用返回的是`value_type`类型对象

需要注意的是下标运算符和at函数只适用于 **非const** 的`map`和`unordered_map`容器。

有时候使用下标运算符来查找我们想要的元素会带来副作用，也就是可能会插入一个新元素，这种行为可能不在我们预期之内，因此尽量避免使用下标运算符来查找元素，除非插入行为是在预期内的。

### 访问、查找元素

关联容器中查找元素的操作如下所示：

|        操作        |                             含义                             |
| :----------------: | :----------------------------------------------------------: |
|    `c.find(k)`     | 返回一个指向 **第一个** 关键字为k的元素的迭代器<br />若k不在容器中，则返回尾后迭代器`c.end()` |
|    `c.count(k)`    | 返回关键字等于k的元素的数量<br />对于不允许重复关键字的容器，返回值永远为0或1 |
| `c.lower_bound(k)` | 返回一个指向 **第一个** 关键字不小于k的元素的迭代器<br />不适用于无序容器 |
| `c.upper_bound(k)` | 返回一个指向 **第一个** 关键字不大于k的元素的迭代器<br />不适用于无序容器 |
| `c.equal_bound(k)` | 返回一个表示关键字等于k的元素的范围的迭代器`pair`<br />若k不存在，则pair的两个成员均为尾后迭代器`c.end()` |

假设我们不能接受下标运算符这种额外的插入行为，那么就最好使用find函数来代替其查找。

对于关键字可以重复的`multimap`和`multiset`，要查找元素的话，相比关键字不能重复的`map`和`set`要复杂一点，但唯一能明确的就是所有关键字相同的元素都是相邻存储的，因此只需要将find函数和count函数配合使用、使用迭代器版本的lower_bound函数和upper_bound函数、使用equal_bound函数都可以访问所有相同关键字的元素。如下所示：
~~~cpp
#include<iostream>
#include<map>
#include<string>

int main(){
    std::multimap<std::string,int> m{
        {"Hello",1},
        {"World",2},
        {"Hello",3},
        {"This",4},
        {"Hello",5}
    };

    //使用find函数和count函数
    auto count = m.count("Hello");
    auto begin = m.find("Hello");
    for(auto i = 0;i<count;i++){
        std::cout << begin->first << " " << begin->second << std::endl;
        begin++;
    }

    std::cout << std::endl;

    //使用lower_bound和upper_bound
    for(auto b = m.lower_bound("Hello"),e = m.upper_bound("Hello");b != e ; b++)
        std::cout << b->first << " " << b->second <<std::endl;
    
    std::cout << std::endl;
    
    //使用equal_bound
    for(auto p = m.equal_range("Hello");p.first != p.second; p.first++)
        std::cout << p.first->first << " " << p.first->second << std::endl;

    return 0;
}
~~~

运行结果如下：
~~~bash
Hello 1
Hello 3
Hello 5

Hello 1
Hello 3
Hello 5

Hello 1
Hello 3
Hello 5
~~~

具体使用哪种方式那就看读者自身的偏好来选择即可。

## 无序关联容器

C++11标准定义了四个无序关联容器，分别是`unordered_map`、`unordered_set`、`unordered_multimap`、`unordered_multiset`。对于无序关联容器，其不是使用比较运算符来组织元素，而是使用一个哈希函数和相等运算符（==）来组织元素。

而无序关联容器在存储上组织为一组桶，每个桶保存0个或者多个元素，容器使用一个哈希函数将每个特定的值映射到桶中。为了访问一个元素，首先就需要计算元素的哈希值，找到其对应的桶，再从中顺序查找我们需要的元素。

因此，无序容器的性能依赖于 **哈希函数的质量、桶的大小和数量**。

### 桶接口

无序容器为了方便用户更好地管理容器，提供了一组可以管理桶的函数，如下表所示：
|          函数          |                             含义                             |
| :--------------------: | :----------------------------------------------------------: |
|   `c.bucket_count()`   |                      正在使用的桶的数量                      |
| `c.max_bucket_count()` |                   容器能容纳的桶的最大数量                   |
|   `c.bucket_size(n)`   |               第n个桶中能容纳的元素的最大数量                |
|     `c.bucket(k)`      | 关键字为k的元素所位于的桶的编号，类型为`size_type`<br />假设元素不存在，也会返回插入这个元素会落在对应桶的编号（实际不会插入） |

### 桶迭代

为了方便地访问桶中的元素，也提供了桶相关的迭代器，如下表所示：
|           函数            |                     含义                      |
| :-----------------------: | :-------------------------------------------: |
|     `local_iterator`      |       可以用来访问桶中元素的迭代器类型        |
|  `const_local_iterator`   |          常量版本的桶元素迭代器类型           |
|  `c.begin(n)`,`c.end(n)`  |     获取第n个桶的首元素迭代器和尾后迭代器     |
| `c.cbegin(n)`,`c.cend(n)` | 获取第n个桶的首元素常量迭代器和尾后常量迭代器 |

### 哈希策略

假设对目前容器的哈希策略不满意，可以通过管理容器的哈希策略来强制容器重组，操作如下表所示：
|         函数          |                             含义                             |
| :-------------------: | :----------------------------------------------------------: |
|   `c.load_factor()`   |              每个桶的平均元素数量，返回float值               |
| `c.max_load_factor()` | 容器试图维护的平均桶大小，返回float值<br />若不满足`load_factor<=max_load_factor`条件，容器会新增桶 |
|     `c.rehash(n)`     | 重新存储<br />使其满足条件`bucket_count>=n`以及`bucket_count>=size/max_load_factor` |
|    `c.reserve(n)`     |        重新存储<br />使得c可以保存n个元素而不必rehash        |

## 关联容器的关键字类型要求

### 有序关联容器

​    这里有一个较难理解的地方，也就是有序关联容器的关键字类型必须要满足 **严格弱序** ，因为有序关联容器一般是由红黑树实现的，红黑树有一个特性：

> 左子树的所有key都小于当前节点，右子树的所有key都大于当前节点。

这意味着如果要根据关键字查找某个值，就必须对关键字进行比较，这就要求有序关联容器的关键字类型必须能够进行 **<** 运算。

而对于严格弱序，C++ 标准并不强制要求关键字类型必须有 `operator<`。它要求你提供的比较器`Compare`必须满足 **严格弱序**（strict weak ordering）。

默认情况下：

```cpp
std::set<Key> s;
```

上述写法等价于：

```cpp
std::set<Key, std::less<Key>> s;
```

而`std::less<Key>`会调用：

```cpp
a < b
```

所以如果`Key`没有`operator<`，默认写法会编译失败。

严格弱序大致要求：

1. `comp(a, a) == false`，不能自己小于自己。
2. 如果 `comp(a, b)` 为真，那么 `comp(b, a)` 必须为假。
3. 传递性：如果 `comp(a, b)` 且 `comp(b, c)`，则 `comp(a, c)`。
4. 等价关系可传递。

其中“等价”定义为：

```cpp
!comp(a, b) && !comp(b, a)
```

意思是：`a` 不小于 `b`，`b` 也不小于 `a`，那么在这个比较器眼里，它们就是等价的。这就是为什么关键字类型必须要能够进行`<`运算的原因。

> [!WARNING]
>
> **等价不一定等于 `==` 相等**。例如：
>
> ```cpp
> struct ByLength {
>     bool operator()(const std::string& a, const std::string& b) const {
>         return a.size() < b.size();
>     }
> };
> 
> std::set<std::string, ByLength> s;
> ```
>
> 在这个set里，`"abc"` 和 `"xyz"` 长度相同，所以它们等价。
> 即使字符串内容不同，`set` 也只会保留其中一个。

假设传递的关键字原生不支持进行`<`运算，则有两种办法来解决这个问题：

1. 重载运算符`<`，例如：

   ~~~cpp
   struct Student {
       int id;
       std::string name;
   
       bool operator<(const Student& other) const {
           return id < other.id;
       }
   };
   
   std::set<Student> s;
   ~~~

2. 提供独立比较器，例如：

   ~~~cpp
   struct StudentCmp {
       bool operator()(const Student& a, const Student& b) const {
           if (a.id != b.id) return a.id < b.id;
           return a.name < b.name;
       }
   };//函数对象方式，重载函数调用运算符"()"
   
   std::set<Student, StudentCmp> s;
   ~~~

   或者

   ~~~cpp
   bool StudentCmp(const Student& a,const Student& b){
       if (a.id != b.id) return a.id < b.id;
       return a.name < b.name;
   }//函数指针方式
                   
   std::set<Student,decltype(StudentCmp)*> s;
   
   //与上述语句等价
   std::set<Student,decltype(&StudentCmp)> s;
   std::set<Student, bool(*)(const Student&, const Student&)> s;
   ~~~

   很明显使用函数对象会更方便，可读性也更高。

### 无序关联容器

无序关联容器同样需要关键字类型能够进行 **`==`运算和`hash`运算**，其中`==`运算与上述有序关联容器的形式无异，只要能提供一个与该运算符功能类似的函数或者重载运算符均可。

但对于hash运算，因为标准库给每个内置类型都定义了一个hash模板，如果我们想要给我们自己的自定义类型也能够作为元素添加进无序关联容器中，也必须要提供我们自己编写的hash模板。

可以利用模板来编写，但这里为了方便演示，就先不使用模板类型来编写示例代码，假设我们有如下类：

~~~cpp
struct Book{
    std::string isbn;
    std::uint32_t price;
};
~~~

为了让我们能够像`std::unordered_map<Book,int>`这样直接放入无序关联容器，我们就必须提供相应的hash函数和等价运算函数：

~~~cpp
std::size_t hasher(const Book &bk){
    return std::hash<std::string>()(bk.isbn);
}

bool eqOp(const Book &lbk,const Book &rbk){
    return lbk.isbn == rbk.isbn;
}

using _unordered_bookmap = std::unodered_map<Book,int,decltype(hasher)*,decltype(eqOp)*>;

//分别提供桶的数量、hash模板、等价运算
_unordered_bookmap store(11,hasher,eqOp);
~~~

如果我们自定义的数据结构能够进行`==`运算，那么可以只重载哈希函数即可。

# 文件的打开和关闭

​	之前讲了如何定义一个文件指针，但是此时指针并没有指向任何文件，要让指针指向文件，则需要用到标准库中的一些库函数。

## fopen函数

位于stido.h头文件中，其函数原型为：

```c
FILE *fopen(const char *path,const char*mode);
```

其用途是**返回一个文件结构体指针，该指针能够指向指定的文件头地址**，这样就打开了一个文件。具体用法是传递一个**文件路径字符串**给path字符串指针，一个**打开文件模式字符串**给mode字符串指针。如果失败，则会返回一个NULL指针。

​	这里简单介绍一下const限定符，这个限定符主要用于**声明常量**，被该限定符修饰的变量的值在后续是无法改变的。这里不过多讲述其用法。

​	打开文件模式共有以下几种：

|      mode       |                含义                |
| :-------------: | :--------------------------------: |
|  **"r"**(只读)  |    为*输入*打开一个**文本文件**    |
|  **"w"**(只写)  |    为*输出*打开一个**文本文件**    |
|  **"a"**(追加)  |     向**文本文件**尾*添加数据*     |
| **"rb"**(只读)  |   为*输入*打开一个**二进制文件**   |
| **"wb"**(只写)  |   为*输出*打开一个**二进制文件**   |
| **"ab"**(追加)  |    向**二进制文件**尾*添加数据*    |
| **"r+"**(读写)  |    为*读写*打开一个**文本文件**    |
| **"w+"**(读写)  | 为*读写* 建立一个**新的文本文件**  |
| **"a+"**(读写)  |    为*读写*打开一个**文本文件**    |
| **"rb+"**(读写) |   为*读写*打开一个**二进制文件**   |
| **"wb+"**(读写) | 为*读写*建立一个**新的二进制文件** |
| **"ab+"**(读写) |   为*读写*打开一个**二进制文件**   |

​	其中“r+”和“a+”以及“rb+”和“ab+”都是以读写打开一个文件，两者区别主要在于含有“r”的模式能够对文本内容进行覆盖写，其文本指针*默认在开头*，**会覆盖原有文件内容**；而含有“a”是对文件内容进行添加，打开文件后文本指针*默认在尾部*，**可以添加内容**。

​	其中含有“w”的读写模式，会清空文件内容，且**只能读入不能读出**，因此要注意，不能用输入模式执行输出操作，反之同理，单纯的读出模式也不能读入。（输入读入表示对文件输入内容，输出读出表示从文件中读取内容输出）

​	且要注意打开文本的形式，其中文本文件为以**“txt”**为后缀的文件，二进制文件存储形式为二进制码，后缀一般没有特定形式。

下面举个例子简单说明fopen的用法：

```c
FILE *fp = fopen("./Main.txt","r+"); 
```

关于文件路径，这里也有必要介绍一下相对路径和绝对路径。

​	在上述例子中我使用的是相对路径，表示的是在编译文件当前目录下寻找Main文本文件。"."表示当前目录，".."表示上一目录。相对路径就是指**选择一个文件为参考（一般是编译文件），然后在该文件的目录开始寻找所需文件**。

​	绝对路径就是**从磁盘开始，详细地给出文件所在位置**，例如：

```c
FILE *fp = fopen("H://CProject//Project5//src//Main.txt","r+"); 
```

​	当然关于地址符”/“，可以用双地址符”//“，也可以用一个，不会用反斜杠”\“，这是为了防止与转义字符产生矛盾（例如\n）。

​	一般来说相对路径更具优势，因为绝对路径要求用户必须要按照给的路径放置文件，而相对路径只需要要求文件相对于程序文件在某些目录里就可以了。移植性更好，通用性更高。

## fclose函数

其位于stdio.h头文件中，其函数原型为：

```c
int fclose(FILE *stream);
```

作用是**关闭文件**，一个文件使用完成后就必须关闭文件，否则有可能会产生误用导致数据损失，关闭后该指针就不会再指向该文件。参数传递为传递一个**文件指针**。

​	当顺利完成了关闭操作后会返回0，否则返回EOF（-1）。

在使用文件时就应该养成一个好习惯，在使用完文件后就应该关闭文件，至于为什么不直接让文件指针指向NULL而是使用fclose函数，这里提出我的猜想：

​	fopen函数会开辟一个临时空间存放文件数据，如果单纯地只是把指针指向NULL却不释放这部分内存，那么后续这部分内存就会一直占用导致内存泄漏。而fclose函数的作用就是释放这部分内存（但指针仍指向这一块区域），以便后续能够继续使用这部分内存。

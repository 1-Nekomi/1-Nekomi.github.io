# 文件读写位置定位

​	之前介绍文件的读写时我们用到了rewind函数，这关系到文件读写位置，怎么理解这个文件读写位置呢，不妨这样设想：我们打开一个文本文件时，文本的起点会有一个光标，可以简单理解为我们操作文件时也有这么一个光标，这个光标就是位置指针，在向文件执行读取或者输入操作后，光标是不会复位的，需要手动进行复位。举个简单例子，当指针打开文档后是这样的：

|China

当我读取了字符串后，光标就变成了这样：

China|

此时就到达了文件尾，如果在执行下一次操作前不讲光标（位置指针）复位到文件头，那么指针就继续往下读无意义内容，从而导致错误，这种错误是隐性的，一般很难发现，因此要养成用完文件后复位文本指针的好习惯。

## rewind函数

​	既然知道了要让位置指针复位到文件头，那么需要一个函数去执行这个操作。

​	rewind函数位于stdio.h头文件中，函数原型为：

```c
void rewind(FILE *stream);
```

作用是**将位置指针重新返回文件开头**，该函数无论失败与否都没有返回值。举个例子：

```c
fputs("China",fp);
rewind(fp);
char s[10] = {'\0'};
char *string = s;
fgets(string,10,fp);
printf("%s",string);
```

这个程序运行是有结果的，但是假设去掉了rewind函数，运行就不会出现结果。这是因为将China字符串输出到文件后，位置指针没有复位，在执行读取操作时，指针会继续往下读无意义内容，形式上体现的就是无内容输出。

## fseek函数和随机读写

​	对流式文件可以顺序读写，也可以随机读写，关键在于控制文件的位置指，就像我们在电子产品上打字一样。如果位置指针是**按字节位置顺序移动**的，那么就是顺序读写；如果能将位置指针**按需要移动到任意位置**，那么就是随机读写。用fseek函数可以实现随机读写。

​	该函数位于stdio.h头文件中，函数原型为：

```c
int fseek(FILE *stream, long int offset, int whence);
```

作用是**在指定文件中基于起始点whence移动offset个字节数**，其中offset位移量需要*在数字后加上字母L*表示该数字为long型（目的是防止文件大小超过64KB后出现问题），起始点whence用0、1、2代替表示，**0表示文件起点，1表示当前位置，2表示文件末尾**。在stdio.h头文件中也有相关宏定义：

```c
#define SEEK_SET 0
#define SEEK_CUR 1
#define SEEK_END 2
```

​	这个就是用于fseek函数起始点参数传递用的

​	fseek函数一般用于二进制文件，也可以用于文本文件，但是由于文本文件要发生字符转换，计算位置时可能会发生混乱，需要谨慎对待。

​	使用例子：

```c
fseek(fp,100L,0);//将位置指针往前移动到离文件头100个字节的地方
fseek(fp,-10L,SEEK_END);//将位置指针往后移动到离文件尾10个字节的地方
```

## ftell函数

​	由于过多地操控位置指针可能会让人无法得知位置指针此时的位置，因此ftell函数可以得到位置指针当前位置。

​	该函数位于stdio.h头文件中，函数原型为：

```c
long int ftell(FILE *stream);
```

作用是**返回一个长整型的数字表示位置指针相对于文件头的字节数距离**。



这里需要详细说明以下为什么fseek最好不要用于文本文件，以一个简单例子进行说明：

```c
#include <stdio.h>

long filesize(FILE *stream);//读取文本字节数 

int main(void)
{
	FILE *fptr;
	
	fptr = fopen("Main.txt", "w+");//创建一个新的文本文件以读写方式打开。 
	fprintf(fptr, "This is a test\n");//输入字符串到文件中 
	printf("Filesize of Main.txt is %ld bytes\n", filesize(fptr));
	fclose(fptr);
	return 0;
}

long filesize(FILE *fptr)
{
	long curpos, length;
	
	curpos = ftell(fptr);//文件头位置 
	fseek(fptr, 0L, SEEK_END);//从文件尾部开始 
	length = ftell(fptr);//获取长度 
	fseek(fptr, curpos, SEEK_SET);//回到文件头 
	return length;
}
```

​	我们运行上述程序会发现程序输出16字节，该文本拥有16字节的数据，但是你去编译文件当前目录下查看该文本文件，会发现，'\n'转义字符并没有出现在文本中，而是以换行的隐性形式出现在文本中。这说明转义字符不会明显地出现在文本中，如果要用fseek操作文本文件就需要考虑转义字符所占用的两个字节，如果不考虑，则会出现位置指针移动错误。

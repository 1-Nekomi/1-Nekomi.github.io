# 文件相关工具函数总结

|   分类   |                           函数原型                           |                    功能                    |
| :------: | :----------------------------------------------------------: | :----------------------------------------: |
| 打开文件 |     FILE ***fopen**(const char *path,const char *mode);      |                  打开文件                  |
| 关闭文件 |                int **fclose**(FILE *stream);                 |                  关闭文件                  |
| 文件定位 |  int **fseek**(FILE *stream, long int offset, int whence);   |           改变文件位置指针的位置           |
|    ↑     |                void **rewind**(FILE *stream);                |       置位位置指针，让其回到文件开头       |
|    ↑     |              long int **ftell**(FILE *stream);               | 返回位置指针此时相对于文件开头距离的字节数 |
| 文件读写 |   int **fgetc**(FILE *stream);int **getc**(FILE *stream);    |                读取一个字符                |
|    ↑     | int **fputc**(int char, FILE *stream);int **putc**(int char, FILE *stream); |                输出一个字符                |
|    ↑     |       char ***fgets**(char *str, int n, FILE *stream);       |                 读取字符串                 |
|    ↑     |        int **fputs**(const char *str, FILE *stream);         |                 输出字符串                 |
|    ↑     |                 int **getw**(FILE *stream);                  |           读取一个字（int类型）            |
|    ↑     |              int **putw**(int w, FILE *stream);              |           输出一个字（int类型）            |
|    ↑     | size_t **fread**(void *ptr, size_t size, size_t nmemb, FILE *stream); |                 读取数据项                 |
|    ↑     | size_t **fwrite**(const void *ptr, size_t size, size_t nmemb, FILE *stream); |                 输出数据项                 |
|    ↑     |    int **fscanf**(FILE *stream, const char *format, ...);    |               按格式读取数据               |
|    ↑     |   int **fprintf**(FILE *stream, const char *format, ...);    |               按格式输入数据               |
| 文件状态 |                 int **feof**(FILE *stream);                  |            若到文件尾返回非零值            |
|    ↑     |                int **ferror**(FILE *stream);                 |          对文件操作出错返回非零值          |
|    ↑     |               void **clearerr**(FILE *stream)                |          使ferror和feof函数值置0           |

​	这些工具函数最好能够记忆，记住不同情形下该用什么函数去实现，这些都需要大量的实验经验。

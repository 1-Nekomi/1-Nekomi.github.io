# 文件概述

​	这部分主要讲述文件的一些的处理，但主要还是以介绍工具函数为基本，工具原理请自行搜索相关文档。

## 文件简介

​	C语言将文件看作一个字符或者字节的序列，由一个个字符有序组合而成的数据。根据数据组合的形式可将文件分为**test（txt）文件**（其每一个字节存放一个字符）和**二进制文件**（将数据在其在内存中的存储形式原封不动地保存在文件中）。两者所占用的存储空间大小不一定相同，这是由于两者存储数据的形式是不一样的。前者更注重*数据的原样*，更直观地能够看出数据的样子，后者更注重*数据的保存形式*，占用的存储空间更小。

​	C语言对文件的操作是基于**指针**进行的，因此这里要求对指针要有一定程度的理解，不然有关内容可能很难理解。

​	在stdio.h头文件中可以找到文件类型结构体的定义：

```c
typedef struct
{
    short level;//缓冲区空或者满的程度
    unsigned flags;//文件状态标志
    char fd;//文件描述符
    unsigned char hold;//如无缓冲区不读取字符
    short bsize;//缓冲区的大小
    unsigned char *buffer;//数据缓冲区的位置
    unsigned ar *curp;//指针，当前的指向
    unsigned istemp;//临时文件，指示器
    short token;//用于有效检查
}FILE;
```

要使用一个文件，就需要用一个文件指针，其定义形式如下：

```c
FILE *fp;
```

这样就能通过fp指针去访问该文件，至于为什么定义指针去使用文件而不是一个变量，因为文件存入内存后，是以二进制形式存在的，然后指针能够在各种工具函数中始终指向该文件的地址，如果使用普通变量，在函数传递时并不能保证一定是传递地址，有可能是值传递，这样就无法保证一定能改变文件中的内容（读是没问题的）。这一定程度上也体现了指针的便利性。

## C对文件的处理方式

分为两种：

①缓冲文件系统：

​	系统自动地在内存区为每一个正在使用的文件开辟一个缓冲区，从内存向磁盘输出数据必须**先送到内存的缓冲区，装满缓冲区后才一起送到磁盘中去**。如果从磁盘中读取数据到内存，则是**依次将磁盘文件数据送入内存缓冲区，装满缓冲区后再逐个将数据送到程序数据区**。缓冲区大小视C版本而定。

②非缓冲文件系统：

​	系统*不会*自动为文件开辟确定大小的缓冲区，而是由*程序*为每个文件设定缓冲区。

用*缓冲文件系统*对文件输入输出的操作称为**高级磁盘输入输出**，用*非缓冲文件系统*对文件的输入输出的操作成为**低级磁盘输入输出**。

​	上述只介绍了最基本关于文件的一些概念，关于文件的详细使用需要用到库函数。

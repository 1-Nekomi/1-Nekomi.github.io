# 出错检测

​	当我们调用函数对文件进行操作时，如果失败会返回一些特定值，同时也会出现文件错误标志，我们可以用函数去进行检测。

## ferror函数

​	位于stdio.h头文件中，函数原型为：

```c
int ferror(FILE *stream);
```

作用**是检测对文件的操作是否成功**，如果设置了与流关联的错误标识符，该函数返回一个非零值，否则返回一个零值。意思是成功执行返回0，失败返回非零值。

使用用例：

```c
char c = fgetc(fp);
if(ferror(fp))
    printf("读取文件失败");
```

## clearerr函数

​	位于stdio.h头文件中，函数原型为：

```c
void clearerr(FILE *stream)
```

作用是**将文件错误标志和文件结束标志清零**，假设在调用一个输入输出函数时出现错误，ferror函数为一个非零值，在调用clearerr函数后，ferror函数的值就会变成0。只有在下一次用库函数对文件进行操作后，ferror函数的值才会发生变化。feof函数同理。



下面举个例子简单说明两个函数：

```c
#include <stdio.h>

int main()
{
   FILE *fp;
   char c;

   fp = fopen("file.txt", "w");

   c = fgetc(fp);
   if( ferror(fp) )
   {
      printf("读取文件：file.txt 时发生错误\n");
   }
   clearerr(fp);
   if( ferror(fp) )
   {
      printf("读取文件：file.txt 时发生错误\n");
   }
   fclose(fp);

   return(0);
}
```

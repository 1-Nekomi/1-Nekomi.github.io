# 文件的读写

​	既然打开了文件，那不可能什么都不做吧。这里介绍一些能够对文件实现读写的库函数。

## fputc函数和fgetc函数及其辅助函数

①**fputc函数**

​	位于stdio.h头文件中，函数原型为：

```c
int fputc(int char, FILE *stream);
```

作用是**将一个无类型参数写入一个文件**，如果成功会返回写入的字符，如果失败，则会返回EOF（-1）。

举个简单例子说明：

```c
FILE *fp = fopen("./Main.txt","r+"); //以读写方式打开文本文件
if(fp == NULL)//检测指针是否指向了文件
	printf("cannot fine the file.\n");
else
{
    if(fputc('a',fp) != EOF)//将字符a写入文件，并检测是否成功
		printf("succes\n");
	else
		printf("fail\n");
}
fclose(fp);
```

注意该函数只能写入字符，无法写入字符串

②**fgetc函数、feof函数**

​	fgetc函数位于stdio.h头文件中，函数原型为：

```c
int fgetc(FILE *stream);
```

作用是**从指定的文件中读取一个字符**，注意该函数只能读取一个字符，无法做到读取字符串。如果读取完毕（遇到文件结束符）则会返回一个文件结束标志EOF（EOF不是可输出字符）。假设确实需要EOF所代表的-1数据怎么办呢，这就需要feof函数。

​	feof函数位于stdio.h头文件中，函数原型为：

```c
int feof(FILE *stream);
```

作用是**测试当前指定文件状态是否为结束状态**，如果文件此时处于结束状态，则返回1（真），反之返回0（假）。要依次读取文件中的内容可以采用以下方式：

```c
while(!feof(*fp)){
    char a = fgetc(fp);
    printf("%c",a);
}
```

这样即使在文件中遇到了-1，也不会被误判为文件结束。

## fread函数和fwrite函数

​	假设在数据特别多的情况下，那么有没有函数能一次性读写数据块呢。

​	fread函数位于stdio.h头文件中，其函数原型为：

```c
size_t fread(void *ptr, size_t size, size_t nmemb, FILE *stream);
```

作用是**读取文件中的数据流到ptr指针指向的数组中去**。其中ptr参数表示**数组的起始地址**，size表示要**读的字节数**，count表示**读多少个size字节的数据项**，stream则为文件指针。如果成功调用则会返回nmemb参数的值，失败则会返回0。

这里举个例子帮助理解：

```c
FILE *fp = fopen("./Main.txt","r+"); 
if(fp == NULL)//检测指针是否指向了文件
	printf("cannot fine the file.\n");
else//文件中写的“China is good.”
{
   char string[15] = {'\0'};
   char *S = string;
   if(fread(S,sizeof(S),1,fp)!=1)
		printf("read fail");
	else
		printf("%s",string);
}
fclose(fp);
```

这里请猜猜输出结果是什么，文本内容会被全部输出到控制台吗，不会的话，为什么？（提示，字符串指针最大8字节），可以用sizeof运算符算一算指针S和string数组的字节数，并将其修正为可以全部读取出来的程序。

​	上述提到，如果调用失败会返回0，但是也有成功改变数值却返回0的情况，例如：

```c
FILE *fp = fopen("./Main.txt","r+"); 
if(fp == NULL)//检测指针是否指向了文件
	printf("cannot fine the file.\n");
else//文件中写的“China is good.”
{
    char string[15] = {'\0'};
    printf("%d\n",fread(string,sizeof(string),1,fp));
    printf("%s",string);
}
fclose(fp);
```

可以看到第一行输出是0，按理来说应该是调用失败，但我们去输出string数组的内容会发现还是成功读取了，之所以会出现这种情况，我们看文件中的字符，会发现只有14个字符，但实际上我们定义的数组长度为15，因此会有一个元素为空，而fread函数会将读到文件结束符（即读到了文件尾）视为一种错误处理，因此就返回0。如果此时我们将数组长度改为14，fread则会返回1。面对这种容器长度大于文件内容的情况要谨慎对待。

​	因此存在调用成功却返回0的情况，原因可能是读取到了文件尾或者发生了未知错误。

​	

​	fwrite函数位于stdio.h头文件中，函数原型为：

```c
size_t fwrite(const void *ptr, size_t size, size_t nmemb, FILE *stream);
```

作用是**将指定数组中的内容写入文件中**。其中ptr参数表示**数组的起始地址**，size表示要**写的字节数**，count表示**写多少个size字节的数据项**，stream则为文件指针。如果成功调用则会返回nmemb参数的值，失败则会返回0。

​	使用原理和注意事项和fread函数类似，这里不再赘述。下面举个简单例子说明：

```c
FILE *fp = fopen("./Main.txt","r+"); 
if(fp == NULL)//检测指针是否指向了文件
	printf("cannot fine the file.\n");
else
{
   char *string = "China is good.";
   printf("%d\n",fwrite(string,sizeof(string),1,fp));
   printf("%s",string);
}
fclose(fp);
```

请自行分析写入文件的内容是什么。

## fprintf函数和fscanf函数

​	fprintf函数、fscanf函数和printf函数、scanf函数类似，只不过读写对象由终端变成了磁盘文件。

两者函数原型分别是：

```c
int fprintf(FILE *stream, const char *format, ...);
int fscanf(FILE *stream, const char *format, ...);
```

前者作用是**输出格式化数据到文件中**，后者作用是**读取格式化数据到程序中**，stream为**文件指针**，format为**格式字符串，也可以是输出字符串**，“···”表示**操作列表**。下面举个简单例子说明：

```c
FILE *fp = fopen("./Main.txt","r+"); 
if(fp == NULL)//检测指针是否指向了文件
	printf("cannot fine the file.\n");
else
{
   char a,b,c,d;
   fprintf(fp,"%c,%c,%c,%c",'a','b','c','d');
   //等价于:fprintf(fp,"a,b,c,d");
   rewind(fp);
   fscanf(fp,"%c,%c,%c,%c",&a,&b,&c,&d);
   printf("%c %c %c %c",a,b,c,d);
}
fclose(fp);
```

其中的rewind函数我们在后面会介绍到，这里可以暂时忽略。主要作用是将文本指针移动到开头。

## putw函数和getw函数

​	位于stdio.h头文件中，函数原型为

```c
int putw(int w, FILE *stream);
int getw(FILE *stream);
```

putw函数主要用于输出一个字（整数）到文件中，getw是从文件中读取一个字（整数）。成功会返回读取或者输出的字，失败返回EOF。下面举个例子说明：

```c
putw(10,fp);
rewind(fp);
int i =getw(fp);
printf("%d",i);
```

请自行分析。

​	注意，有些C编译系统并不提供这两个函数，但可以自己定义，两者定义过程如下：

```c
int putw(int w,FILE *fp){
    char *s;
    s = (char*)&w;
    putc(s[0],fp);
    putc(s[1],fp);
    return w;
}

int getw(FILE *fp){
    char *s;
    int i;
    s = (char*)&i;
    s[0] = getc(fp);
    s[1] = getc(fp);
    return i;
}
```

​	因为存入文本文件是**以字符存入**的，因此这里定义一个字符串指针，指针有8个字节，不管多少，系统都会将其分为两个部分，即s+0和s+1，s+0指向数字w的第一个字节，s+1指向数字w的第二个字节，而s[0]和s[1]等价于*(s+0) 和 *(s+1)，结合图来看可能更好理解一点：

​																				   数字10的字节

| 0000 0000 | 0000 1010 |
| :-------: | :-------: |

​										    s[0]																						s[1]

## fgets函数和fputs函数

​	前面的fgetc函数和fputc函数都是只能输出或输入一个字符，假设有一个字符串，那用些会更方便：

​	fegts函数和fputs函数位于stdio.h头文件中，函数原型为：

```c
int fputs(const char *str, FILE *stream);
char *fgets(char *str, int n, FILE *stream);
```

前者是**输出一个字符串到文件中**，后者是**从文件里读取一个长度为n的字符串到程序中**，参数含义过于明显，不予介绍。成功前者会返回非负值，失败返回EOF，后者成功会返回一个指向字符串头元素地址的指针，失败会返回空指针。

使用例子：

```c
fputs("China",fp);
rewind(fp);
char s[10] = {'\0'};
char *string = s;
fgets(string,10,fp);
printf("%s",string);
```

请结合上述原理自行分析。

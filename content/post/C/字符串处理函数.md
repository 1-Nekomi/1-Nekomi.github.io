# 字符串处理函数

## 1.printf、scanf相关

​	位于stdio.h头文件中，%s，例如：

```c
scanf("%s",s);
printf("%s",s);
```

缺陷：无法读取空格，例如：china 123，只会读取china。

优点：可以连续读取不同字符串到不同字符数组中。

例如：输入 china 123 fine

使用语句：

```c
scanf("%s%s%s",str1,sctr2,str3);
```

此时str1 = "china",str2 = "123", str3 = "fine"。



## 2.puts函数

​	位于stdio.h头文件中，一般形式为：

```c
puts(字符数组);
```

​	该函数在其输出的字符串中可以包含转义字符。（当然，printf("%s")也可以做到）。

例如：

```c
char s[] = {"China\nBei jing"};
puts(s);
```

输出为：

China

Bei jing



## 3.gets函数

​	位于stdio.h头文件中，一般形式为：

```c
gets(字符数组);
```

​	该函数解决了%s无法读取空格的缺陷。但是无法做到连续读取字符串。

例如：china 123 fine ,无法连续读到三个不同字符数组中，只会连续读到一个字符数组中。



## 4.strcat函数

​	位于string.h头文件中，一般形式为：

```c
strcat(字符数组1,字符数组2);
```

​	该函数**能够连接两个字符串。将s2连接到s1后面，调用后得到s1的地址**。使用时要注意给s1留足空间，若连接时发生空间不足，则会出现信息丢失。s2可以为常量，例如:

```c
strcat(s1,"china")
```

但s1不能为常量。

​	其进行连接时会将s2后方的'\0'取消，只在新字符串后方保留'\0'。

使用举例：

```c
char s1[30] ={"china is "};
char s2[] = {"good"};
printf("%s",strcat(s1,s2));
```

输出为：

china is good

## 5.strcpy函数和strncpy函数

​	位于string.h头文件中，一般形式为：

```c
strcpy(字符数组1,字符串2);
strncpy(字符数组1,字符串2,前n个字符);
```

strcpy作用是**将字符串2的内容复制到s1**中，字符串2可以是一个常量，例如：

```c
strcpy(s1,"china");
```

但s1不能为常量。

strncpy则会将**字符串2的前n个字符复制到字符数组1**中，取代s1中最前面n个字符，例如：

```c
strncpy(s1,s2,3);
```

​	注意：如果在进行复制前，没有对s1进行初始化，且s2的长度（假设为6）小于s1长度（假设为10），则s1前6个字节是s2的内容，但后4个字节的内容是无法预知的（因为没有初始化），不一定为'\0'。



## 6.strcmp函数

​	位于string.h头文件中，一般形式为：

```c
strcmp(字符串1,字符串2);
```

​	作用是**对字符串1和字符串2进行相似性比较**，遇到不同字符或者'\0'结束，比较结果以第一个不同字符的比较结果为准，其中字符串1和字符串2均可以为常量。

​	比较结果以函数返回值为准：

①如果字符串1 = 字符串2，返回0；

②如果字符串1 > 字符串2，则返回一个正整数；

③如果字符串1 < 字符串2，则返回一个负整数。

对于字符串谁打谁小的比较，一般根据**第一个不同字符对应ASCII码值**进行比较，**越靠后的字母越大，小写字母比大写字母大**。



## 7.strlen函数

​	位于string.h头文件中，一般形式为：

```c
strlen(字符数组);
```

​	作用是**测试字符串长度**。函数返回的值为字符串的实际长度，不包含'\0'。例如：

```c
strlen("china");
```

返回的值为5。



## 8 .strlwr函数

​	位于string.h头文件中，一般形式为：

```c
strlwr(字符串);
```

作用是**将字符串中的大写字母换成小写字母**。



## 9.strupr函数

​	位于string.h头文件中，一般形式为：

```c
strupt(字符串);
```

作用是**将字符串中的小写字母换成大写字母**。

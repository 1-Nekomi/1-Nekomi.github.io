# 多重指针和指针函数、指针数组

​	本节内容主要包含：①指向指针的指针（俗称多重指针）；②指针函数（注意不是函数指针，指针函数本质属于函数）；③指针数组。

首先介绍多重指针：

## 多重指针

​	我们都知道指针本质属于地址，能够指向变量，但是要知道指针实际上也是一种变量类型，因此就衍生出了一种指针：*其指向指针，意思就是其地址指向的是一个指针变量*。接下来举个例子来简单介绍其用法：

```c
#include<stdio.h>

void main(){
	int **p = NULL;
	int a = 5;
	int *A = &a;
	
	void PR(int*);
	
	p = &A;
	
	PR(*p);
}

void PR(int *a){
	printf("%d",*a);
}
```

​	首先定义一个指向int类型指针的指针变量p，然后定义一个指向int类型变量的指针变量A并让A指向一个值为5的变量a，将指针变量A的地址赋给多重指针p，然后调用一个参数表包含一个int类型指针变量的函数，对指针指向的变量值进行输出。

从上述程序不难看出，在调用函数PR时，取出了指针p中的内容，而指针p是指向指针A的，这样就将指针A的地址传递给了PR函数，因此下列两个语句其实是等价的：

```c
PR(*p);
PR(A);
```

由此可以得知，多重指针的用法和普通指针用法实际上并无多大区别，只是指向对象变为了一个指针，但其实际上还是属于**单个变量的指针**。

​	实际上，这种“嵌套”可以是无限的，上述是二重指针，也可以有三重指针，四重指针，以此类推没有上限。但是“嵌套”得越多就越复杂，不利于程序的可读性，且大多嵌套没有实际意义，因此二重指针就已经是极限了。

## 指针函数

​	介绍完了多重指针，紧接着介绍指针函数，顾名思义就是返回值是一个指针的函数。其定义形式一般如下：

```c
数据类型	*函数名称（参数表）
```

下面举个例子简单说明指针函数的用法：

```c
#include<stdio.h>
//找出最大的一个数 
 
void main(){
	int *function(int (*)[]);
	int num[][3] = {{1,4,5},{2,3,9},{6,8,7}};
	int (*p)[] = num; 
	printf("%d ",*(function(p)));
}

int *function(int (*pt)[3]){
	int i,j;
	int max = *(*(pt));
	int *p = &max;
	for(i = 0;i < 3;i++){
		for(j = 0;j<3;j++){
			if(*(*(pt+i)+j) > *p)
				*p = *(*(pt+i)+j);
		}
	}
	return p;
}
```

​	关键在于function函数中，在这个函数中，首先将传递进来的指针指向的数组中第一个元素作为最大值，然后赋给变量max，再由一个指针p指向max变量，并在后续比较中交换最大值，最后返回指针p给调用语句，然后利用指针运算符取出其中的内容进行输出。

​	这里需要注意，上述的function函数只能返回一个int类型的指针变量，且该指针指向的对象是一个int类型变量，假设我想要返回一个int类型指针变量，其指向的是一个数组，那函数应该怎么定义呢。请思考下列操作是否是正确的：

```c
int (*)[]function(){
    ...
}
```

答案是错误的，这样编译器会报错，实际上函数的返回值定义是这样的：

```c
int (*function())[]{
	...
}
```

​	不妨这样思考：编译器首先是先定义函数，例如上述，编译器先定义名字为function的函数，然后这个函数返回什么呢，编译器就看到了除开function()后的内容：int (*)[]，这样编译器就明白了返回值是一个指向int类型数组的指针。同理，这样也可以用于其他返回值函数的定义。

​	请思考，一个名为fun的函数(无参数表)，其返回值为一个指向*字符串*的指针，该如何定义？

正确答案：

```c
char *fun(){
    ...
}
```

## 指针数组

​	指针变量本质也是一种变量类型，因此，指针也是可以有数组的，其定义形式跟指向数组的指针细微差别：

```c
数据类型	*指针名称[元素个数];
```

这样就定义了一个能够容纳指定个数指针的数组，在这个数组中存放的都是指针，可以简单理解为一个地址集合，其中存放的全是地址。这样定义多个指针时就能够省力一点，例如：

```c
int i;
char *p[3] = {"China","Is","Good"};
for(i = 0;i<3;i++)
	printf("%s ",p[i]);
```

请读者自行分析，注意结合“指针和字符串”的知识，思考p[i]指向谁的地址。为什么不用(*p)[]来指向一个字符串。

​	指针数组还可以作为main函数的形参使用，但实用性不高，如果感兴趣可以自行搜索资料。这里只提及一下作为形参使用的main函数定义形式：

```c
void main(int argc,int *argv[]);
```

argc和argv都由命令行赋予，属于程序外的操作，这里涉及了命令指令的知识，因此不予介绍。

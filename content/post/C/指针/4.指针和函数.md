# 指针和函数

   指针除了可以指向一个变量、数组、字符串外，还可以指向函数。接下来简单介绍一下指针使用函数的方法：

​	由数组那部分的知识我们不难看出，数组名字本身是数组第一个元素的地址。而对于函数也类似，函数名字本身是函数的接口地址，因此可以通过下列操作让一个指针指向函数：

```c
void (*p)(int,int) = NULL;
void function(int,int);
p = function;
```

## 指向函数指针定义

​	指向函数的指针定义和指向一个数组的指针定义类似，请回忆一下一个指向5个元素的数组指针是如何定义的。

```c
int *p[5];
```

请思考上述定义语句是否正确，如果不正确，请自行修改成正确的形式。

假设存在一个函数原型：

```c
int function(int (*)[],int);
```

请结合上述代码尝试自行写出一个指针定义，能够指向这个函数。

正确的定义形式是这样的：

```c
int (*p)(int (*)[],int) = function;
```

完整的定义形式是这样的：

```c
#include<stdio.h>

void main(){
	int function(int (*)[],int);
	int (*p)(int (*)[],int) = function;
}
int function(int (*p)[],int j)
{
	...
}
```

从上述程序不难看出，要定义一个函数指针的一般形式是这样的：

```c
数据类型	（*指针名称）（函数参数列表）;
```

其中指针名称两边的括号**不能省去**，否则会识别成一个指针函数（返回指针值的函数，本质是函数）。且需要注意，给指针赋址的时候，不能带上函数的参数表，只需要函数名即可，例如下述操作是错误的：

```c
p = function(*p1,j);
```

这个语句本质属于调用函数语句，而不是赋址语句。下述操作就是正确的赋址操作，能让指针正确指向函数入口：

```c
p = function;
```

## 用处

​	指针指向函数后，要利用指针调用函数的语句只需要**将函数名和带上指针运算符后的指针名进行调换**即可，例如：

```c
int add(int,int);
int reduce(int,int);
int (*p)(int,int) = reduce;
int c = add(a,b);
int d = (*p)(a,b);
```

请自行尝试分析上述程序并进行总结。

​	让指针指向函数有什么用呢？

①作为函数参数传递，请阅读下列程序：

```c
#include<stdio.h>

void main(){
	void function(void (*)(int*,int*,int*),int*,int*,int*);
	void add(int*,int*,int*);
	
	int *p1 = NULL,*p2 = NULL,*p3 = NULL;
	int a = 10,b = 3,c;
	p1 = &a;p2 = &b;p3 = &c;
	
	function(add,p1,p2,p3);
	
	printf("%d",*p3);
}
void function(void (*p)(int*,int*,int*),int *p1,int *p2,int *p3)
{
	(*p)(p1,p2,p3);
}
void add(int *p1,int *p2,int *p3)
{
	*p3 = *p1+*p2;
}
```

​	首先该程序声明了两个函数，一个中间函数function，一个执行函数add（中间函数用于调用执行函数）。定义了三个int类型指针指向三个变量，然后在主程序中调用中间函数，传递add函数的入口地址给一个void类型函数指针，并在中间函数通过指针参数对执行函数进行调用，最后执行加法并将结果传递给对应变量的指针。

​	上述程序写得很刻意，最终目的还是学习函数指针的用途，因此不用太在意。

②提高函数通用性，例如：

```c
#include<stdio.h>

void main(){
	void add(int*,int*,int*);
	void reduce(int*,int*,int*);
	
	void (*p)(int*,int*,int*) = NULL;
	int a = 10,b = 7,c,d;
	int *p1 = &a,*p2 = &b,*p3 = &c;
	
	scanf("%d",&d);
	
	if(d == 1)
		p = add;
	else
		p = reduce;
	
	(*p)(p1,p2,p3);
	printf("%d",*p3);
}

void add(int *p1,int *p2,int *p3){
	*p3 = *p1+*p2;
}

void reduce(int *p1,int *p2,int *p3){
	*p3 = *p1-*p2;
}
```

这样可以在**不改变整体框架的情况下在同一语句调用不同函数**，有利于提高函数的通用性。要调用不同函数，只需要改变指针的指向对象即可。但需要注意指针不能指向任意一个函数，其只能指向与其参数表数据类型相同的函数，例如下列指针定义是错误的：

```c
int function(int);
int (*p)(int,int);
p = function;
```

不仅如此，函数指针也不能指向与其数据类型不同的函数，例如下列操作就是错误的：

```c
void function();
int (*p)();
p = funtion;
```

​	在本节中举的例子大多比较刻意，如有更好的例子欢迎指正。

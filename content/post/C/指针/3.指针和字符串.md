# 指针和字符串

​	这里介绍指针的一种应用：字符串操作

​	在介绍这部分内容前，请读者自行回忆在学习指针前，对字符串的使用是如何进行的。

​	下面举个指针使用字符串的简单例子供读者参考：

```c
char *string = "China";
printf("%s\n",string);
```

​	请将其与不使用指针的方法进行对比，找出区别。不难看出，其与不使用指针的方法其实并无区别，只是输出对象由字符数组变为了指针。

​	但是，这里先提及一下前面的数组内容，这里第一个语句，并不是对指针赋值字符串，而是将字符串地址赋给指针，本质上是这样的：

```c
char *string = NULL;
char a[] ={"China"};
string = a;
```

只是省去了定义另一个变量的过程，但不能理解为将China字符串赋给指针，指针内存放的依然是地址。

​	其赋址原理与一维数组类似，这里不再赘述。

​	注意，在指向字符串的时候，我们指向一个变量通常只用一个指针变量*****，指向一个数组则需要用一个指向数组的特殊指针**( * )[]**，字符串本质属于一维数组，指向字符串不需要用到( * )[]这种形式，只需要像指向一个变量那样定义一个普通char类型指针即可，因为指针本质上**指向的是字符串第一个字符的地址**。只有在用到*字符串数组*时才会用到 ( * )[]这种形式，这种形式本质上**指向的是整个字符串**，跟前者有所区别。但是字符串数组一般可以用数组指针来代替使用，后者更为直观，详细请看“指针数组”对应文档。

​	字符串的使用也与一维数组存在许多共通之处，个人认为没什么必要讲太多，只需要知道指针如何能够指向字符串就行。下面讲字符串指针和字符数组的一些小区别：

## 字符串指针和字符数组

​	其区别如下：

①字符数组本身存放的是字符串，而指针本身存放的是字符串的地址（字符串第一个字符的地址）；

②两者赋值方式不同，指针可以像上述程序那样直接赋址，但字符数组就不能，例如下面这些操作是错误的：

```c
char a[] = {'\0'};
a = "China";
char b[] = {'\0'};
b[] = "China";
```

其赋值只能这样：

```c
char c[] = {"China"};
```

③指针在使用前必须指定一个具体的字符串对象，而字符数组不需要。

​	原因详见“指针概念”。

④指针变量的值允许改变，字符数组不允许。例如

```c
char *a ="I Love China";
a += 7;
printf("%s",a);
```

运行结果为：China

原理详见“指针与数组”，同理，可以通过运算符来输出字符串中任意一个字符，请读者自行尝试。

⑤用指针指向一个特殊字符串，能代替格式字符串使用。例如：

```c
int a = 6;
float b =4.3;
char *format = "a = %d,b = %f\n";
printf(format,a,b);
```



这部分的内容相对较少，因为跟数组的相通性很多，只有一小部分区别。可以在练习中自行学习。

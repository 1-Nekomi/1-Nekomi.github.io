# 指针

​	指针本质属于地址，其中地址的内容属于被指向的对象，指针主要用于以下一些场景：**数组处理、字符串处理、函数处理、指针本身**。

在讲述上列应用场景前，先了解指针是什么。

## 内存与指针

​	注意：学习这部分内容前最好对变量存储有所了解，能有内存的概念。

​	当我们定义变量的时候，编译器对其进行编译时变量会被分配到内存中，对变量的值存储都是通过内存中的地址进行的。程序在编译后，变量名已经变为变量的地址。

​	那么指针就是*用于存储变量地址*的一种数据类型。指针可以用于使用这个变量，下面举个例子来说明：

例1：

```c
int a = 5;
printf("%d",a);
```

例2：

```c
int *p = NULL;
int a = 5;
p = &a;
printf("%d",*p);
```

通过指针可以进行很多操作，因为知道了这个变量的地址。具体有哪些操作详见其他部分。

​	因此**指针就是一个变量的地址**，指针变量中存储的值就是被指向变量的地址。



## 指向单个变量的指针

​	由上述例子其实就可以看出来了，指针定义形式一般如下：

```c
数据类型 *变量名;
```

前面的数据类型代表*指针指向对象的数据类型*，并不是说指针的数据类型。例如一个指针需要指向类型为double的变量，那么数据类型应该声明为double，然后声明其名称，注意不要漏掉*运算符。

​	既然定义了指针，那么就可以引用指针。指针的引用涉及两个运算符：

①&，取址运算符，用于取出指定对象的地址；

②*，指针运算符，取出被指向对象内容，我称其为取值运算符（但实际能不能这么叫待定）；

​	上述讲到指针本质属于地址，那么指针变量就不能存放其他值，例如这种就是无意义的：

```c
int *p = NULL;
p = 2000;
```

​	因此指针中只能存放变量的地址，要取一个变量的地址，就要用“&”运算符，仔细想想在前面我们是不是也用到过这个运算符？

​	没错，scanf输入函数中也用到了这个运算符，原理也是一样的，读取输入设备输入的内容后存放到对应变量的地址中。

​	存放了地址后，怎么取出指针指向对象中的内容呢，这就用到了“*”运算符。按照下列操作就能取出指针中的内容：

```c
int *p = NULL;
int a = 5;
int b;
p = &a;
b = *p;
```

这样b的值也就变成了5。

如果在对b赋值操作的语句中不加*，那么b的值就会变成a的地址，而不是a的值。

​	这里需要注意一下，在对指针进行定义的时候，*在定义语句中不是作为运算符存在的，而是作为一种声明，告诉编译系统这是指针变量。

​	这时你可能会注意到我定义指针变量的时候给指针指向了一个NULL，这个NULL是什么呢。NULL的宏定义可以在stdio.h头文件中找到，*本质是0字符串*，在内存中，地址0是不存在的，给指针进行初始化的目的是为了**防止指针乱指向一些不该指向的地址**，也就是俗称的野指针的一种。让指针指向NULL可以让这个指针暂时不发挥作用。

​	这里讲讲为什么有必要在指针定义时进行初始化。在学习变量存储的时候我们都知道，如果一个变量不进行初始化便使用有可能会产生错误的值，其中的值是不可预估的。指针也是如此，如果不对指针进行初始化或者使用指针前让其指向一个具体对象，那么指针中存放的地址值也是不可预测的，假设其中的值正好存放有重要信息，那么就会对重要信息造成破坏，造成信息损失。

​	因此使用指针前一定要让其*指向一个具体可用的对象*，例如下列使用方式就是错误的：

```c
int *p;
scanf("%d",p);
```

这里的p指针并不知道指向的哪个地址，胡乱赋值可能会造成信息损失。

​	由此就知晓了指针最基本的用法和使用规则。

# 预处理命令

## 1.宏定义

### (1).不带参数的宏定义

​	一般形式为：

```c
#define 标识符 字符串
```

作用是在程序中**用指定标识符替换字符串**，在编译时会将宏定义展开。且预编译时不会对宏定义进行语法检查。例如：

```c
#define PI 3.1415926

void function(){
   	area = PI*r*r;
    ...
}
```

宏定义的作用域一般为*定义命令后到本文件尾*。可以用*#undef*命令来终止宏定义的作用域。例如：

```c
#define PI 3.1415826

void f1(){
    ...
}
#undef PI
void f2(){
    ...
}
```

这样f1函数可以使用PI宏定义，但f2不能使用PI宏定义。

​	注意：宏定义不属于c语句，不需要在句尾打分号。



### (2).带参数的宏定义

​	一般形式为：

```c
#define 宏名（参数表） 字符串
```

作用同上，例如：

```c
#define add(a,b) a+b

void add(){
    result = add(3,5);
}
```

​	对于带有参数的宏定义展开过程描述是这样的：如果程序中如果有带实参的宏，则按#define命令行指定的字符串从左到右进行置换。如果串中包含宏中的形参，则将程序中的实参代替形参。如果宏定义中的字符串中的字符不是参数字符，则保留。

​	使用宏定义可以避免过多地定义简单函数。节省一定的运行时间，因为宏定义替换字符串是在编译时完成的，只占用编译时间。

​	接下来介绍在使用宏定义过程中易犯错的地方：

请看下述程序：

```c
#include <stdio.h>
#define DIV(X,Y) X*Y

int main() {
  int a = 3, b= 5;
  printf("%d", DIV(a + 1, b - 3));
  return 0;
}
```

程序运行结果为：5

​	奇怪，不应该是（3+1）*（5-3）= 4 * 2 = 8吗，为什么输出结果为5呢，这就涉及到了宏定义的展开，见上述。实际上，在这里宏展开后的结果是a+1*b-3，代入后结果很显然结果为5。

​	因此在宏定义时需要尤其注意，参数不一定只是单个字符或者数字，有可能是一个表达式或者字符串，所以保险起见，可以在宏定义时给参数打上括号，例如上述宏定义改成这样运算结果就是正确的：

```c
#define DIV(X,Y) (X)*(Y)
```

 程序运行结果为：8

由这个例子不难看出，对带参数的宏的展开只是**将语句中的宏名后面括号内的实参字符串代替#define命令行中的形参**。

​	在使用宏定义时还需要格外注意下：

①宏名与带参数的括号之间不应该加空格，否则参数表会被视为被替代字符串中的一部分；

②宏定义只是简单的字符串替换，并不能完全替代函数使用；

③宏定义并不是只能替换简单的表达式和字符串，一定程度上也能替换语句使用，例如：

```c
#define CIRCLE(R,S,V,L) R *= L; S = V+R;
```

其适用范围非常灵活，关键在于使用者。

接下来举个简单例子供读者参考：

```c
#include<stdio.h>
#define PR printf
#define NL "\n"
#define D "%d"
#define D1 D NL
#define D2 D D NL
#define D3 D D D NL
#define D4 D D D D NL
#define S "%s"

void main(){
	int a,b,c,d;
	char string[] = "China";
	PR(D1,a);
	PR(D2,a,b);
	PR(D3,a,b,c);
	PR(D4,a,b,c,d);
	PR(S,string);
}
```

运行结果如下：

```c
1
12
123
China
```

请读者自行分析。



## 2.文件包含处理

​	这部分使用过c的读者都非常熟悉，原理简单介绍一下就是：**将指定的文件中的内容”复制粘贴“到预处理语句这里来**。#include命令本质属于宏命令，在编译时会将被包含文件在包含文件中进行展开。也就是复制粘贴了（但不等同于复制粘贴）。一般用于头文件处理，当然特殊情况下可以用于包含c文件。

​	其一般形式有两种：

```c
#include "文件名"
```

```c
#include <文件名>
```

​	两者区别在于**寻找方式**，用双引号时，系统会优先在编译文件当前用户目录下寻找要被包含的文件，如果不存在则会在C标准库函数中去寻找；用尖括号时，系统会直接在C标准库函数中去寻找。

​	一般来说，如果被包含的.h文件和.c文件是自己写的，用双引号包含，如果是包含标准库文件，则用尖括号。

​	除这两种形式外，还有一种特殊形式：

```c
#include "被包含文件路径"
```

这种形式不同于另外两者，其是直接通过给出的路径去寻找文件，一定程度上可以减少编译时间。

​	这部分内容其实还有很多，比如被包含文件中假设存在变量，则在包含文件中不能重复定义，也不需要用extern来拓展变量作用域。但大多都可以通过实验来自主学习，理论上不太需要过多说明。因此这里只介绍了一些常见的情况。



## 3.条件编译

​	一般而言，整个程序的所有语句都会参与编译，但是假设我希望有一小部分只有满足了一定条件才会编译时，那应该怎么办呢。这就涉及到了”**条件编译**“。

​	涉及以下几种预编译指令：

| #define  |                       定义一个预处理宏                       |
| :------: | :----------------------------------------------------------: |
|  #undef  |                         取消宏的定义                         |
|   #if    |        编译预处理中的条件命令，相当于C语法中的if语句         |
|  #ifdef  |        判断某个宏是否被定义，若已定义，执行随后的语句        |
| #ifndef  |             与#ifdef相反，判断某个宏是否未被定义             |
|  #elif   | 若#if,  #ifdef, #ifndef或前面的#elif条件不满足，则执行#elif之后的语句，相当于C语法中的else-if |
|  #else   | 与#if,  #ifdef, #ifndef对应, 若这些条件不满足，则执行#else之后的语句，相当于C语法中的else |
|  #endif  |         #if, #ifdef, #ifndef这些条件命令的结束标志.          |
| #defined |         与#if,  #elif配合使用，判断某个宏是否被定义          |

​	一般有三种形式：

①

````c
#ifdef 标识符
	待编译代码块1
#else
    待编译代码块2
#endif
````

这种形式的意思如下：若在**if命令前存在** *一个宏名为该标识符的定义*，则编译代码块1，否则编译代码块2。例如：

```c
#define SoS 0
#ifdef SoS
	printf("a = %d",a);
	printf("\n");
#else
	printf("a = %d,b = %d\n",a,b);
#endif
```

编译结果为编译代码块1。

②

```c
#ifndef 标识符
	代编译代码块1
#else
    待编译代码块2
#endif
```

该形式若在**if命令前不存在** *一个宏名为该标识符的定义*，则编译代码块1，否则编译代码块2。例如：

```c
#define None 1
#ifndef None
	...代码块1
#else
    ...代码块2
#endif
```

这样就会编译代码块2。

③

```c
#if 表达式
	待编译代码块1
#else
    待编译代码块2
#endif
```

这种形式编译哪部分取决于表达式的真假，若**表达式运算结果为真**，则*编译代码块1*；反之**为假**，则*编译代码块2*。注意表达式必须使用宏定义，变量无效。

例如：

````c
int a = 1;
#define a 0
#if a
	printf("OK");
#else
	printf("NO");
#endif
````

结果是输出NO。

那么还请读者思考条件编译可以用于什么情况下，能有什么好处？

思考完后，这里提出我的见解：

①能有效地舍弃特殊情况下不必要的代码，减少代码长度，缩短编译时间。

​	举个例子，比如将一个字符串中的所有小写字母变成大写，所有大写字母变成小写字母。一般情况下，一个字符串里是会存在小写字母和大写字母混有，但是假设输入字符串中全是小写字母，那么将大写字母变为小写字母这部分代码就不需要了。一定程度上可以减少编译时间。

②可以方便进行调试。

​	假设为了调试，你的代码里有一万个调试语句，调试完后一个一个去删显然很费时间很费精力，但是利用条件编译，只需要一个宏定义就能启动调试。例如：

```c
#define Debug
#ifdef Debug
	调试语句
#endif
```

或者

```c
#define Debug 1
#if Debug
	调试语句
#endif
```

每次调试你只需要宏定义一个debug就能很方便地启动调试。

​	但说实话条件编译其实用得很少，毕竟现在计算机功能实在强大，小项目多一点编译时间少一点编译时间都无所谓，但对于一些大项目而言，条件编译还是比较有用的。

# 格式输入与输出



## 	1.转义字符及其作用

| 字符形式 |              含义              | ASCII代码 |
| :------: | :----------------------------: | :-------: |
|    \n    | 换行，将当前位置移到下一行开头 |    10     |
|    \t    |            水平制表            |     9     |
|    \b    |   退格，将当前位置移到前一列   |     8     |
|    \r    |  回车，将当前位置移到本行开头  |    13     |
|    \f    |  换页，将当前位置移到下页开头  |    12     |
|   \\\    |     代表一个反斜杠字符“\”      |    92     |
|   \\'    |       代表一个单引号字符       |    39     |
|   \\"    |       代表一个双引号字符       |    34     |
|   \ddd   |   1到3位八进制数所代表的字符   |           |
|   \xhh   |  1到2位十六进制数所代表的字符  |           |

## 	

## 		2.printf格式字符

| 格式字符 |                             说明                             |
| :------: | :----------------------------------------------------------: |
|   d,i    |         以带符号的十进制形式输出整数，整数不输出符号         |
|    o     |                  以八进制无符号形式输出整数                  |
|   x,X    | 以十六进制无符号形式输出整数（不含前导符0x），用x则输出十六进制数的a~f以小写形式输出。用X时是大写形式 |
|    u     |                  以无符号十进制形式输出整数                  |
|    c     |                 以字符形式输出，只含一个字符                 |
|    s     |                       以字符串形式输出                       |
|    f     |         以小数形式输出单、双精度数，隐含输出6位小数          |
|   e,E    |  以指数形式输出实数，e、E为指数大小写（1.23e+02、1.23E+02）  |
|   g,G    | 选用%f或者%e中输出宽度较短的一种形式，不输出无意义的0，大小写区别指数e、E |

## 	

## 		3.printf的附加格式说明字符

|        字符         |                             说明                             |
| :-----------------: | :----------------------------------------------------------: |
|        l，L         |          用于长整型整数，可加在格式符d、o、x、u前面          |
| m（代表一个正整数） | 数据最小宽度，若输出对象宽度>m，则完全按照对象长度进行输出，若<m，则默认在左边补空格。若包含“—”，则在右边补空格 |
| n（代表一个正整数） | 对实数，表示输出n位小数；对字符串，表示截取的字符个数。若长度<n,则以0补足，字符串以空格补足。 |
|          —          |          输出的数字或者字符在域内向左靠，例如%-m.nd          |



## 			4.scanf格式字符

| 格式字符 |                             说明                             |
| :------: | :----------------------------------------------------------: |
|   d,i    |                    输入有符号的十进制整数                    |
|    u     |                    输入无符号的十进制整数                    |
|    o     |                    输入无符号的八进制整数                    |
|   x,X    |                   输入无符号的十六进制整数                   |
|    c     |                          输入单字符                          |
|    s     | 输入字符串，接收对象为一个字符数组，在输入时以非空白字符开始，以第一个空白字符结束。字符串以串结束标志‘\0'作为其最后一个字符 |
|    f     |            输入实数，可以用指数形式或小数形式输入            |
| e,E,g,G  |                 与f作用相同，三者可互相调换                  |



## 		5.scanf的附加格式说明字符

| 字符 |                             说明                             |
| :--: | :----------------------------------------------------------: |
|  l   | 输入长整型数据（%ld、%lo、%lx、%lu）以及双精度数据（%lf、%le） |
|  h   |               输入短整型数据（%hd、%ho、%hx）                |
| 域宽 |      输入数据所占宽度（列数），应为一个正整数，例如%4d       |
|  *   |        表示本输入项在读入后不赋给相应的变量，例如%*3d        |

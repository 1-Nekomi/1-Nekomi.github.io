# 算术类型转换

​	C++在遇到不同类型进行转换的时候会将两个数进行适当的类型转换，然后再进行运算。转换顺序如下：

char						unsigned char
  ↓								 		↓
short int				unsigned short
 ↓										 ↓
int							unsigned int
 ↓										 ↓
long int					unsigned long
 ↓											 ↓
long long int			unsigned long long
		--------------↓----------------
						float
							↓
						double
							↓
					long double				

例如一个char类型数和int类型数进行计算，char类型会先转换为int类型后在进行计算。

​	不过在实际应用中还是需要注意不同数据类型最好不要进行运算。避免最坏的情况发生。

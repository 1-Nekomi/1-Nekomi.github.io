# 运算符

## 1.关系运算符及其优先次序

| 运算符号 |    含义    | 优先次序 |
| :------: | :--------: | :------: |
|    <     |    小于    |    高    |
|    <=    | 小于或等于 |    高    |
|    >     |    大于    |    高    |
|    >=    | 大于或等于 |    高    |
|    ==    |    等于    |    低    |
|    !=    |   不等于   |    低    |

四个运算符的优先级相同，都为高；后两个运算符的优先级相同，都为低

且有以下关系：

①关系运算符的优先级低于算术运算符

②关系运算符的优先级高于赋值运算符



## 2.逻辑运算符及其优先次序

1.**&&** 逻辑与（and）有一假则全为假

2.**||** 逻辑或（or）有一真则全为真

3.**！** 逻辑非（not）取反

优先级次序满足以下关系：

​			高↑ 	！（非）

​				|	算术运算符（+、-、*、/、%）

​				|	关系运算符（<,>,<=,>=,!=,==)

​				|	&& 和||

​			低|	赋值运算符(=) 



## 3.位运算符

| 运算符 |   含义   |
| :----: | :------: |
|   &    |  按位与  |
|   \|   |  按位或  |
|   ^    | 按位异或 |
|   ~    |   取反   |
|   <<   |   左移   |
|   >>   |   右移   |

1.按位与（&）

​	两个二进制位均为1，否则输出结果为0，例如

0&0 = 0，0&1 = 0，1&1 = 1

思考：3&5的结果是多少？

​			0000 0011

  <u>（&）0000 0101</u> 

​    		0000 0001



2.按位或（|）

​	两个二进制位有一个为1，否则输出0，例如

0|0 = 0，0|1 = 1，1|1 = 1

思考：48|15的结果是多少？

​			 0011 0000

​	<u>(|)	0000 1111</u>

​     		0011 1111



3.异或（^）

​	两个二进制位同号输出0，异号输出1。例如

1^0 = 1, 0^0 = 0, 1^1 = 0

思考：57 ^ 42结果为多少？

​			0011 1001

​	<u>(^)	0010 1010</u>

​     		0001 0011



4.取反（~）

​	被运算的二进制位为1则输出0，否则输出1。例如

~1 = 0，~0 = 1

思考：八进制数25的取反结果为？

​			0000 0000 0001 0101

（~）  1111 1111 1110 1010



5.左移运算符（<<）

​	将一个数的二进制码全部左移若干位。高位左移后溢出，舍弃。

​	左移一位相当于该数乘2，前提是被舍弃高位中不包含1。例如：

1110 0010 <<3 = (111)0001 0000

0000 0011 <<4 = (0000)0011 0000

​	思考：对于127左移三位后结果为什么？

0111 1111 << 3 = (011) 1111 1000



6.右移运算符（>>）

​	将一个数的二进制码全部左移若干位。低位溢出舍弃。

​	右移一位相当于该数除以2，前提是被舍弃低位中不包含1。例如：

0000 0010 >> 1 = 0000 0001(0)

1010 0101 >> 4 = 0000 1010(0101)

​	思考：对于64右移四位结果为什么？

0100 0000 >> 4 = 0000 0100(0000)



### 其他

​	对于右移左移运算符，在实践中发现如果对一个变量同时左移右移相同位数，则变量值不会发生改变，例如：

​	char f = 0x44；

则f<<2>>2 == f。这说明高位（低位）溢出的1不会被系统置位变为0，而且溢出的低位高位会参与计算。例如：

​	char num = 0xE5;

​	printf("0x%X",(~(0xE5<<4))>>4);

输出结果为0x1A，正好为0xE5的取反结果，这个过程中高位溢出过，但仍参与了计算。因此为不影响结果，溢出的高低四位有必要进行置0。置0方法为在进行左移右移计算时，先对低位或者高位进行置0，例如：1101 1010（0xDA）

我要右移四位，则需要将低四位置0，可以这样做：0xDA & 0xF0。同理，高四位也可以通过这种方式置0。

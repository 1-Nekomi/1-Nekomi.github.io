# 结构体与指针

该部分涉及指针，如果对指针不熟练，请自行跳过。

## 指向结构体变量的指针

​	指针要指向结构体变量的方法跟指针指向一个基本数据类型变量方法类似，一般形式如下：

```c
struct 结构体名 *指针名 = &结构体变量名;
```

下面举个简单例子：

```c
struct student{
    int num;
    char *name;
    int age;
}stu1 = {10,"Rose",17};
struct student *p;
p = &stu1;
```

这样就成功将p指针指向了stu1结构体变量，那么假设需要通过指针引用结构体stu1中的成员变量num该如何引用呢？通过指针引用成员变量的形式有下面几种：

```c
(*指针名).成员变量名;
指针名->成员变量名;
```

意思就是上述问题可以这样写：

```c
(*p).num;
p->num;
```

都是没有问题的。其中“**->**”被称为指向运算符，表示获取指针p指向的结构体变量中的成员变量的值。这里需要注意，第一种形式指针名四周的括号不能省，如果省去就等价于*(p.num)，我也不知道什么意思，但引用指针成员变量是不需要“ * ”运算符的。

​	那么请尝试分析下面几种运算：

````c
p->num++;//先获取p指针指向的结构体变量中的num成员变量的值再使其自增1
++p->num;//先使p指针指向的结构体变量中的num成员变量的值自增1再获取
````

## 指向结构体数组元素的指针

​	说完了指向单个结构体变量的指针，接下来介绍指向结构体数组的指针，其与一维数组原理有共通之处，可以先尝试回忆指针指向一维数组的相关操作原理。

​	请尝试回答以下问题：

①指针如何得到数组的地址，得到的具体是谁的地址，是整个数组吗，如果不是那是谁的？

②如何改变指针的指向对象？

先看问题一：

​	在一维数组中我们获取一维数组地址是通过直接将数组名赋予给指针，这里同理，**只需要将结构体变量名赋予指针，指针就会自动指向*头元素的地址***。注意不是整个数组的地址。

​	下面举个简单例子：

```c
struct teacher{
    int num;
    char *name;
    int age;
}teach[3] = {{1000,"john",39},{1001,"jake",42},{1002,"Kendy",23}};

struct teacher *p = teach;
for(;p<teach+3;p++)
    printf("%d %s %d\n",p->num,p->name,p->age);
```

运行结果自行调试。

再看问题二：

​	请先回忆，一维数组指针是如何改变指向的，移动字节数是如何计算的。然后请注意上述程序，你可能注意到了teach+3这个表达式，实际上teach是头元素的地址，对地址进行进行加减运算，系统会根据结构体占用总字节数，乘上运算值，得到指针应该移动多少字节。

​	整体来看，是不是发现这个跟一维数组指针并无区别。实际上在社区中流传一种说法：“**结构体可以当作一种自定义数据类型处理，这个数据类型占用字节数，内容完全自定义**”，这一点在后面介绍“typedef声明”尤其突出。

关于作为函数参数进行传递，原理部分也跟一维数组较为相似，请自行分析学习，这里不赘述。

​	指针在结构体这一部分拥有重要地位，别看内容确实只有这么点，但实际上，指针对于结构体来说非常重要，其中一个广为人知的应用就是**线性链表**，其原理简单介绍一下就是：结构体变量内含有一定数量基础成员变量和一个必需结构体指针，这个指针用于指向下一个结构体变量所在的地址，同样下一个结构体变量内也有下下一个结构体变量的地址，一个接着一个，像锁链那样。关于“线性链表”会在“数据结构”课程接触到，这里不过多介绍，感兴趣请自行了解。

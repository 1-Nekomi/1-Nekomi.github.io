# 链表处理函数和运算符

注意，这部分与其说介绍，不如说是工具文档，这里介绍了一些用于处理链表的工具函数，在了解这部分前，最好能够对链表的底层工作原理有所了解。明白什么是“动态链表”和“静态链表”。

## malloc函数

位于malloc.h头文件中，函数原型为：

```c
void *malloc(unsigned int size);
```

作用是**在内存的动态存储区中分配n个长度为size字节的连续空间**。函数会返回一个**指向分配区域起始地址**的指针，类型为空类型（void），在使用时需要进行强制类型转换，如果未能成功执行操作，则会返回空指针（NULL）。

## calloc函数

位于malloc.h头文件中，其函数原型为：

```c
void *calloc(unsigned n,unsigned size);
```

其作用是**在内存的动态存储区中分配n个长度为size字节的连续空间**。函数会返回一个**指向分配区域起始地址**的指针，类型为空类型（void），在使用时需要进行强制类型转换，如果未能成功执行操作，则会返回空指针（NULL）。用于一维数组的动态存储空间管理。

## realloc函数

位于标准库stdlib.h头文件中，函数原型为：

```c
void *realloc(void *ptr,unsigned size);
```

作用是**为已动态分配了内存的区域重新分配内存大小**，其中prt表示*指针指向的一个内存块区域*，size表示要*重新分配内存的大小*，若成功则会返回指向该内存块区域头的指针，失败则返回NULL。

## free函数

位于malloc.h头文件中，其函数原型为：

```c
void free(void *p);
```

其作用是**释放由p指向的动态存储区**，使这部分内存区能够被其他变量使用。p是最近一次调用calloc或malloc函数时返回的值。free函数无返回值。

​	注意：用malloc和calloc函数分配内存后，如果后续不再需要使用这段内存，一定要使用free函数去释放这段内存，否则这段内存不会被覆盖，会一直占用，如果内存占用过多则会发生内存溢出，这是极其危险的，一定要注意。

## sizeof运算符

​	很多人以为这个属于函数，实际上sizeof属于一种运算符，用于计算数据类型或者指定对象的字节数，前面提到过，一维数组名为头元素地址，但在这里不代表头元素地址，而是代表整个数组，因为这里的含义是指定数组对象给sizeof运算符，计算整个数组占用字节数。例如：

```c
sizeof(int);
sizeof(float);
sizeof(double);
sizeof(a);//a为数组
```



## 例子

接下来举个简单例子参考：

```c
struct student{
    int num;
    char *name;
    int age;
};

struct student *p = (struct student *)malloc(sizeof(struct student));

p->num = 1000;
p->name = "Ace";
p->age = 19;

printf("%d %s %d\n",p->num,p->name,p->age);
```

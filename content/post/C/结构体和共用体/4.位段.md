# 位段

假设我手中有一组数据 1101 1010 0101 1000

我将其按照每四位划分区域 a，b，c，d

假设我想改变c区域的值为1010而不想动其他区域，该怎么做呢？

下面有两种方法：

## 1.逻辑处理

​	已知1010为四位二进制，我可以将其右移四位变成 1010 0000，这样可以看作

0000 0000 1010 0000

​	然后对原数据进行置0，即将原数据的c区域变为0000（与1111 1111 0000 1111进行按位与&运算），再对0000 0000 1010 0000进行按位或|运算，即可得到最终结果：

1101 1010 1010 1000

## 2.位段

​	C语言允许在一个结构体中以位为单位来指定成员所占内存长度。这种以位为单位的成员称为“位段”或“位域”。利用位段能够用较少的位数存储数据。定义举例：

​	

```c
struct pack_data{
    unsigned a:2;
    unsigned b:6;
    unsigned c:4;
    unsigned d:4;
    int i;
}data;
```

|  a   |  b   |  c   |  d   |  i   |
| :--: | :--: | :--: | :--: | :--: |

​	这样一来，就有了四个位段：a占2位，b占6位，c占4位，d占4位，i位于另一字节开头。当然，也可以不恰好占满。

```c
struct pack_data{
    unsigned a:2;
    unsigned b:3;
    unsigned c:4;
    int i;
};
struct pack_data data;
```

|  a   |  b   |  c   | ////// |  i   |
| :--: | :--: | :--: | :----: | :--: |

​	这里由于没有占满，因此a,b,c后面7位空间闲置不用。

​	对位段中的数据引用可以这样做：

```c
data.a = 2;
data.b = 7;
data.c = 9;
```

如果赋值超过了位域的最大值，例如a域最大值只有3，赋更高的值只会默认赋予数的低位。

关于位段的定义和引用需要注意：

①位段成员类型必须指定unsigned或者int类型；

②若某一段要从另一个字开始存放，可以进行下列操作：

```c
unsigned a:1;
unsigned b:2;//a,b为同一存储单元
unsigned  :0;
unsigned c:3;//c为另一单独存储单元
```

​	本来a，b，c要被连续放入一个存储单元中，但是由于中间插入了一个长度为0的位段，这个的作用是使下一个位段从下一个存储单元开始存放。上述存储单元视不同编译系统可能为1字节，也可能为2字节。

③一个位段必须存储在统一存储单元中，不能跨单元。如果第一个单元空间不能容纳下一个位段，则该空间不用，从下一个单元起存放该位段。

④可以定义无名位段，但无名位段不会被使用。定义例子：

```c
unsigned  :2;
```

⑤位段长度不能大于存储单元的长度，也不能定义位段数组。

⑥位段可以用整型格式符输出，例如：
```c
printf("%d,%d,%d",data.a,data.b,data.c);
```

​	也可以用%u、%o、%x等格式输出。

⑦位段可以在数值表达式中引用，它会被系统自动地转换为整型数。例如

```c
data.a +8/data.b -data.c
```

是合法的。

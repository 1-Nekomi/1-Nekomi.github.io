# 结构体概念

​	我们知道了最基本的变量类型：整型，实型，字符串等，但是假设我需要一个变量类型，其中必须包含一些成员类型，例如一个人的基本信息有姓名，性别，生日，住址，电话，身份证号。为了方便管理使用，必须将他们整合在一起，  成为一个组合项。这种**在一个整体内包含多个类型不同数据项**的数据结构叫做“结构体”。

## 结构体的定义

​	既然要使用结构体，那就必须先定义结构体。结构体的定义形式一般为：

```c
struct 结构体名{
  成员类型	成员名;  
};
```

​	结构体内的成员包含所有基本类型，包括int，float，double，单变量，数组，字符串，指针等等。甚至成员还可以再包括一个结构体，也就是“**嵌套结构体**”。下面举个例子简单了解结构体的定义：

```c
struct student{
     char *name;
     int stu_num;
     int age;
     char *sex;
}stu1 = {"joker",1000,20,"M"},stu2 = {"lover",1001,19,"F"};

struct Class{
  	int class_num;
  	struct student;
};

struct Class class1 = {2,stu2},class2 = {1,stu1};

struct {
    int teacher_num;
    char *name;
    int age;
    char *sex;
}teacher1 = {10000,"John",37,"M"};
```

由上面定义可以看出结构体定义有三种形式。接下来逐一解释：

①结构体名，结构体变量同时定义：

​	这种定义形式较为经典，一般是结构名和对应变量同时在一条语句中定义，这种结构的好处是*看起来紧凑，且容易知道变量有哪些*。缺点是*当变量数量多时，不好对变量中的成员进行管理*。

②结构体和结构体变量分开定义：

​	这种形式将结构体定义和其变量分开进行了定义，好处是*程序看起来更为整洁，条理明顺*。缺点是*变量定义语句不一定就在结构体定义语句后面，有可能会降低程序的可读性*。（意思是变量定义语句和结构体定义语句中间可能会穿插其他东西，导致你看错或者看漏变量定义语句）。

③无结构体名定义：

​	这种形式与第一种形式的区别只是去掉了结构体名，直接定义了变量。优点是*一定程度上能简化程序*，缺点是*不方便引用结构体，只能引用结构体变量*。

上面三种定义形式有利有弊，需要自行根据程序选择合适的定义形式。

​	同时，我们可以看出，第三个结构体和第一个结构体中有相同的成员变量，但编译器编译能顺利通过，这是因为**结构体定义时是不会分配内存的，只有定义结构体变量时才会分配内存**，结构体变量占用内存字节数大小是**所有成员变量占用字节数总和**，不同结构体变量占用的内存都是不一样的，因此就算不同结构体中有相同的成员变量，也不会出现冲突，因为**它们分配到的内存是不一样的**。

## 结构体以及其变量的引用

​	在上面的第二种形式中其实就包含了结构体引用的例子。

```c
struct Class{
  	int class_num;
  	struct student;
};

struct Class class1 = {2,stu2},class2 = {1,stu1};
```

 这里引用了该语句上面定义的student结构体，说明该结构体成员中包含student结构体。

​	既然定义了结构体变量，且结构体变量中包含有许多成员变量，那该怎样引用成员变量呢？引用形式一般如下：

```c
结构体变量名.成员变量名
```

例如上述例子中，我想引用Class结构体中的class_num，那么只需要如下：

```c
int i = class1.class_num;
```

这样就能顺利引用class1中的class_num。那假设我想引用结构体Class中student结构体中的age，那么又该怎样引用呢。

```c
int age = class1.stu2.age;
```

当然这里可以忽略前面的class. 因为student结构体是独立于Class结构体定义的。但假设student结构体没有独立于Class定义，那么就需要前面带上class. ，这表示引用Class结构体中的student结构体成员变量。

​	在引用成员变量的同时需要注意：

①

```c
class1.stu2.age++;
```

**"."表示成员（分量）运算符**，优先级属于**最高级别**，因此上述语句应该是student结构体中的age成员变量自增1。

②在引用结构体成员变量时，需要注意并不能直接引用结构体成员变量本身，例如这个就是错误的：

```c
class1.stu2
```

只能引用结构体成员变量中的次级成员变量。

③可以引用成员变量的地址，也可以引用结构体变量的地址：

```c
scanf("%d",&class1.stu2.age);
printf("%o",&class1.stu2);//输出class1中stu2成员的地址
```

但*不能整体读入数据*：

```c
scanf("%s %d %d %s",&class1.stu2);
```

这种就是错误的操作。

④结构体在使用前一定要确保**其中的成员变量存有有效数据**，可以通过**初始化或者读入**的方式让成员变量存有有效数据，为什么这么做请结合“变量的初始化”自行分析。

## 结构体数组

定义结构体数组的方式也较为简单，只要在定义时声明其变量为数组即可，一般形式有下面几种：

```c
struct 结构体名{
	成员变量
};
struct 结构体名 变量名[] = {初始化内容};

struct 结构体名{
 	成员变量   
}变量名[] = {初始化内容};

struct {
 	成员变量   
}变量名[] = {初始化内容};
```

下面举个例子：

```c
struct teacher{
    int num;
    char *name;
    int age;
}teach[3] = {{1000,"john",39},{1001,"jake",42},{1002,"Kendy",23}};
```

​	结构体数组的分配跟数组类似，都是各个结构体变量占用一块连续的内存空间，请回忆数组内存占用情况，再将数组对象由基本数据类型变为结构体变量，请自行画出结构体的占用情况，这里不予展示。

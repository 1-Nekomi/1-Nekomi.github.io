# 枚举类型

​	如果一个变量只有几种可能的值，则可以定义为枚举类型。枚举的意思就是指**将变量的值一一列举出来，变量的值只限于列举出来的值的范围内**。

​	关键字为：**enum**

## 定义

​	假设定义一个星期，这个星期只有可能是星期一到星期天中的任意一个值，那么就可以这样定义：

```c
enum week{mon,tue,wed,thu,fri,sat,sun}week1;
enum week week2;
```

这样变量的值只可能是上述七种之一，其中的mon到sun都属于用户定义的标识符，被称为“枚举元素”或者“枚举常量”，这些标识符并不自动代表什么含义，且**不能对它们赋值**，因为它们不属于变量。例如下述操作就是错误的：

```c
mon = 1;
week1.mon = 1;
```

但是枚举元素是拥有值的，且能够赋给枚举变量，也能独立输出。其值是默认从左到右依次加1，最左边的值为0。

```c
week1 = mon;
printf("%d\n",week1);
printf("%d",tue);
```

同时枚举类型在定义时能够自行初始化，例如上述的week可以改成这样：

```c
enum week{sun = 7,mon = 1,tue = 3,wed,thu,fri,sat}week1;
```

增加顺序依然从左到右，从最小到最大。那么请思考，wed的值是多少。是4，这是因为系统从左到右只会从最左边没有初始化的值开始，从其左边那个值开始递增，上述wed左边的值是3，因此wed就是4而不是2。那么请思考下述情况时，tue和thu的值：

```c
enum week{sun=7,mon=1,tue,wed=3,thu,fri,sat}week1;
```

tue = 2,thu = 4。

同时要注意避免**同一枚举元素序列里面出现多个同样的值**。

虽然普通的方法无法给枚举变量赋值，但是可以通过强制类型转换来对它们赋值，例如：

```c
week1 = 2;//错误的赋值方法
week1 = (enum week)2;
week2 = (enum week)(10-8);
```

这种不要求序列表中存在一个值为2的枚举元素。但最好选一个序列表中有这么一个值的枚举元素，以方便管理。

## 用途

​	可以用于做判断比较，例如：

```c
if(week1 == mon)...
if(week2 > sun)...
```



​	其实我觉得枚举类型并不算很好用，但在某些情况下它能更直观地体现变量的唯多可能性，也不会因为变量乱赋值而导致程序运行错误，因为枚举变量赋值相对一些普通变量类型具有一定门槛（需要强制类型转换）。

# 共用体

​	我们知道结构体占用字节数是所有成员变量占用字节数总和，但是假设有这么一种情况，就是各个成员变量并没有同时使用，意思就是**一段时间内只有一个成员变量的值具有实际意义**，如果此时还用结构体，不仅变量利用率降低了，还大大增加了内存的开销，有没有一个自定义数据类型能够在一个时间段内只有一个成员变量生效，其他无效呢，这就是共用体的作用。

## 定义

​	共用体在一个时间段内，只有一个成员变量发挥作用，因此它所占用的字节数取决于**占用字节数最大的那个成员变量**，且所有成员变量占用同一段内存，意思就是**其地址都为同一个**。其定义形式一般如下：

```c
union 共用体名{
    成员变量
}变量表列;
```

例如：

```c
union data{
  int stu;
  int tea;
  int cla;
}a;
```

## 成员变量引用

​	由于同一段时间内只有一个成员变量发挥作用，因此，谁发挥作用关键看**最后被赋值的是谁**，其引用成员变量的方式与结构体相同，例如上述共用体：

```c
a.stu = 0;
a.tea = 1;
a.cla = 2;
```

最后这个地址存放的就是cla成员变量的值，如果此时引用stu和tea成员则会以报错处理，因为此时地址中只有cla一个成员变量，其他成员变量没有发挥作用。

​	在这里请回忆一下“作用域”和“生存期”的概念，与共用体联合起来思考如果要画出成员变量的作用域和生存期该怎么画。

​	注意，引用时跟结构体一样，不能引用共用体本身，例如下面这个就是错误的：

```c
printf("%d",a);
```

虽然此时共用体中只有一个成员变量是有效的，但依旧需要告诉系统需要输出谁的值，这是因为*每个成员变量占用的字节数有可能不同*。

## 特点和注意事项

①共用体只用一段内存，这段内存大小取决于成员变量中占用字节数最大的那一个。每一个成员变量的地址都相同，占用同一个地址，意思就是：

```c
&a.stu = &a.tea = &a.cla
```

(注意这个不是语句，是表达式)；

②共用体发挥作用的成员是最后一次被赋值的成员，在存入一个新成员后，其他成员失效。

③不能对共用体变量名赋值，不能企图引用变量名来得到一个值，也不能在定义共用体的时候对其初始化。例如下列操作都是错误的：

```c
union data{
    int i;
    float j;
    double m;
}a = {1,2.3,4.987};//不能初始化

a = 3;//不能整体赋值

int n = a;//不能引用整体
```

④**不能把共用体变量作为函数参数**，也不能使函数带回函数共用体，但**可以使用指向共用体的指针**（用法与结构体指针类似）。

⑤共用体类型可以成为结构体成员变量，同样也有共用体数组，同时结构体、数组也可以成为共用体成员变量。

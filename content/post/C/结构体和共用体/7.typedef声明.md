# typedef声明

​	该声明主要用于*重命名已有类型*，以达到用一个新的类型名来代替已有的类型名。例如：

```c
typedef int INTEGER;
INTEGER i;
```

这样就可以用INTEGER带代替int，这与宏定义有一点类似，但区别在于宏定义只能替代简单的字符串，在*预编译期间*完成，而typedef声明在*编译期间*完成，能够完成一定复杂度的重命名，例如结构体类型重命名。同时需要注意的是：**建立一个typedef类型时并没有分配内存空间**。

## 基本类型

​	基本类型除了上述讲到的之外，还可以重命名数组类型，例如：

```c
typedef int NUM[10];
NUM i,j;
```

这样就一次性定义了两个长度为10的数组，省去了重复操作。

​	可以重命名指针类型，例如：

```c
typedef int (*POINT)();
POINT p;
```

这样也能够定义一个指向无参数表函数的指针，很方便批量定义变量。

那么请自行思考重命名字符串指针的重命名

```c
typedef char *String;
String string;
```

总结一下，通过对基本类型重命名声明一个新类型的步骤是：

①按定义变量的方法写出定义体(int n[10];) ;

②将变量名替换成自己想要重命名的类型名字(int NUM[10];) ;

③在前面加上typedef关键字(typedef int NUM[10];) ，然后用重命名后的类型名去命名变量(NUM num;) 。

注意：**typedef只能用于声明新类型名，不能用于定义变量**。



## 结构体变量

​	结构体稍微复杂一点，但也可以套用上面的步骤。例如：

```c
typedef struct student{
    int num;
    char *name;
    int age;
}STU;
STU student1 = {1000,"Lisa",16};
```

这里将student结构体的定义主体变为DY，实际上这个语句就是这样的：

```c
typedef DY STU;
```

等价于：

``` c
typedef struct student STU;
struct student{
    int num;
    char *name;
    int age;
};
```

这样一来就一目了然了，想想之前我们定义结构体变量是怎样定义的。是不是要在变量名前面加上struct和结构体名，这样过于复杂了，而且如果使用typedef重命名，实际上结构体名在定义过程中也可以省去，上面就可以写成这样：

```c
typedef struct{
    int num;
    char *name;
    int age;
}STU;
STU student1 = {1000,"Lisa",16};
```

这样直接用重命名的类型名来定义变量比原来使用结构体类型定义变量要简单不少。
